# v7.3.x Test Execution Worksheet

Use this worksheet to **execute** the build and regression checklist step by step and record evidence.

Recommended usage:
- Duplicate one section per build or release candidate.
- Fill in the metadata first.
- Mark `PASS`, `FAIL`, `BLOCKED`, or `N/A` for each row.
- Add concrete evidence such as screenshot name, console log, `/dashboard-download` snippet, build log line, or browser/version.
- Treat any row marked **Blocker** as release-stopping until resolved.
