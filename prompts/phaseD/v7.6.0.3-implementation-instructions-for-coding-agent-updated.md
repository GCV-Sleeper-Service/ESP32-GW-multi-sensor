## 4) Exact Scope (§3.5)
### 4.1 Endpoint contract
`POST /api/aggregator/test-satellite?url=http://...`

### 4.2 Branches
- 405 wrong method
- 400 missing URL
- 400 invalid URL format (if enforced in add path, keep consistent)
- 400 probe failed/unreachable/invalid manifest
- 200 success with gateway summary fields

### 4.3 Shared probe logic
Reuse `probe_satellite_manifest_()` from add flow (or factor now if missing).

### 4.4 Success response (hybrid hardening)
Return gateway summary:
- `id`
- `name`
- `hardware`
- `sensor_count`

### 4.5 Side-effect prohibition
- No `satellite_caches[]` writes
- No `runtime_satellite_count` changes
- No NVS writes

### 4.6 Data flow trace
```text
POST test-satellite(url)
  → validate url
  → probe manifest
  → extract gateway summary
  → return 200
(no list mutation, no NVS writes)
```
