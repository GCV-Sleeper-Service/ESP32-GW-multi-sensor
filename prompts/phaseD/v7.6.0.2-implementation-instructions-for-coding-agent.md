## 5. Exact Scope — Implement `DELETE /api/aggregator/satellite/{id}`

Replace the 501 stub with a working implementation. **No dashboard changes. No test changes.**

### 5a. API contract

```
DELETE /api/aggregator/satellite/{satellite_id}
```

The satellite ID is parsed from the URL path. It is a string match against `satellite_caches[i].id`.

### 5b. Data flow trace

```
DELETE request arrives
  → parse satellite ID from URL path (after "/api/aggregator/satellite/")
  → validate ID is non-empty
  → AGG_LOCK()
    → scan satellite_caches[0..runtime_satellite_count-1] for matching .id
    → if not found → AGG_UNLOCK() → 404
    → found at index `del_idx`:
      → shift satellites[del_idx+1 .. runtime_satellite_count-1] down by one
      → clear the vacated last slot: satellite_caches[runtime_satellite_count-1].clear_cache()
        → also zero out id_buf[0], name_buf[0], url_buf[0]
        → set id = "", name = "", base_url = ""
      → runtime_satellite_count--
  → AGG_UNLOCK()
  → save_satellites_to_nvs_()  [FULL rewrite — not single save]
  → return 200 {"ok":true}
```

### 5c. ⚠️ CRITICAL: Array compaction invariant

After deleting satellite at index `del_idx`:

1. All satellites at indices `del_idx+1` through `runtime_satellite_count-1` shift down by one position
2. The last occupied slot is cleared
3. `runtime_satellite_count` is decremented
4. **NVS is fully rewritten** via `save_satellites_to_nvs_()` (which calls `nvs_erase_all()` first)
5. No code anywhere stores an index that persists across this operation

**Compaction implementation:**

```cpp
// Shift satellites down to fill the gap
for (int j = del_idx; j < runtime_satellite_count - 1; j++) {
  // Copy identity fields via set_identity (uses owned buffers)
  satellite_caches[j].set_identity(
      satellite_caches[j + 1].id,
      satellite_caches[j + 1].name,
      satellite_caches[j + 1].base_url,
      satellite_caches[j + 1].poll_interval_seconds);
  // Copy cached response buffers
  memcpy(satellite_caches[j].manifest_json, satellite_caches[j + 1].manifest_json,
         satellite_caches[j + 1].manifest_len + 1);
  satellite_caches[j].manifest_len = satellite_caches[j + 1].manifest_len;
  memcpy(satellite_caches[j].live_json, satellite_caches[j + 1].live_json,
         satellite_caches[j + 1].live_len + 1);
  satellite_caches[j].live_len = satellite_caches[j + 1].live_len;
  memcpy(satellite_caches[j].status_json, satellite_caches[j + 1].status_json,
         satellite_caches[j + 1].status_len + 1);
  satellite_caches[j].status_len = satellite_caches[j + 1].status_len;
  // Copy state fields
  satellite_caches[j].last_manifest_fetch = satellite_caches[j + 1].last_manifest_fetch;
  satellite_caches[j].last_live_fetch = satellite_caches[j + 1].last_live_fetch;
  satellite_caches[j].last_status_fetch = satellite_caches[j + 1].last_status_fetch;
  satellite_caches[j].reachable = satellite_caches[j + 1].reachable;
  satellite_caches[j].last_seen_epoch = satellite_caches[j + 1].last_seen_epoch;
  satellite_caches[j].consecutive_failures = satellite_caches[j + 1].consecutive_failures;
}
```

**⚠️ Why not `memcpy(&satellite_caches[j], &satellite_caches[j+1], sizeof(SatelliteCache))`?** Because the `id`, `name`, `base_url` pointer fields would end up pointing to `satellite_caches[j+1]`'s buffers, not `satellite_caches[j]`'s own buffers. Using `set_identity()` ensures each struct's pointers point to its own owned storage. The cached response buffers are safe to raw-copy because they are `char[]` arrays (not pointers).

```cpp
void handle_delete_satellite_(AsyncWebServerRequest *request) const {
  if (request->method() != HTTP_DELETE) {
    send_json_error_(request, 405, "Method not allowed");
    return;
  }

  // Parse satellite ID from URL path
  const char* p = request->url().c_str();
  const char* id_start = p + 26;  // skip "/api/aggregator/satellite/"
  if (*id_start == '\0') {
    send_json_error_(request, 400, "Missing satellite ID");
    return;
  }

  // Find and delete under mutex
  int del_idx = -1;
  if (AGG_LOCK() == pdTRUE) {
    // Find by ID scan
    for (int i = 0; i < runtime_satellite_count; i++) {
      if (strcmp(satellite_caches[i].id, id_start) == 0) {
        del_idx = i;
        break;
      }
    }

    if (del_idx < 0) {
      AGG_UNLOCK();
      send_json_error_(request, 404, "Unknown satellite");
      return;
    }

    ESP_LOGI(TAG_AGG, "Deleting satellite[%d]: id=%s", del_idx, satellite_caches[del_idx].id);

    // Compact: shift remaining satellites down
    for (int j = del_idx; j < runtime_satellite_count - 1; j++) {
      satellite_caches[j].set_identity(
          satellite_caches[j + 1].id,
          satellite_caches[j + 1].name,
          satellite_caches[j + 1].base_url,
          satellite_caches[j + 1].poll_interval_seconds);
      memcpy(satellite_caches[j].manifest_json, satellite_caches[j + 1].manifest_json,
             satellite_caches[j + 1].manifest_len + 1);
      satellite_caches[j].manifest_len = satellite_caches[j + 1].manifest_len;
      memcpy(satellite_caches[j].live_json, satellite_caches[j + 1].live_json,
             satellite_caches[j + 1].live_len + 1);
      satellite_caches[j].live_len = satellite_caches[j + 1].live_len;
      memcpy(satellite_caches[j].status_json, satellite_caches[j + 1].status_json,
             satellite_caches[j + 1].status_len + 1);
      satellite_caches[j].status_len = satellite_caches[j + 1].status_len;
      satellite_caches[j].last_manifest_fetch = satellite_caches[j + 1].last_manifest_fetch;
      satellite_caches[j].last_live_fetch = satellite_caches[j + 1].last_live_fetch;
      satellite_caches[j].last_status_fetch = satellite_caches[j + 1].last_status_fetch;
      satellite_caches[j].reachable = satellite_caches[j + 1].reachable;
      satellite_caches[j].last_seen_epoch = satellite_caches[j + 1].last_seen_epoch;
      satellite_caches[j].consecutive_failures = satellite_caches[j + 1].consecutive_failures;
    }

    // Clear the vacated last slot
    int last = runtime_satellite_count - 1;
    satellite_caches[last].id_buf[0] = '\0';
    satellite_caches[last].name_buf[0] = '\0';
    satellite_caches[last].url_buf[0] = '\0';
    satellite_caches[last].id = satellite_caches[last].id_buf;
    satellite_caches[last].name = satellite_caches[last].name_buf;
    satellite_caches[last].base_url = satellite_caches[last].url_buf;
    satellite_caches[last].poll_interval_seconds = 0;
    satellite_caches[last].clear_cache();

    runtime_satellite_count--;
    AGG_UNLOCK();
  } else {
    send_json_error_(request, 503, "Mutex timeout");
    return;
  }

  // Respond immediately — bulk NVS rewrite deferred to its own task
  // (Critical Rule 40: save_satellites_to_nvs_ does nvs_erase_all + full rewrite)
  auto *resp = request->beginResponse(200, "application/json", "{\"ok\":true}");
  add_common_headers_(resp);
  request->send(resp);

  schedule_save_satellites_nvs_();  // fires after response is queued
}

// Deferred task for bulk NVS save (must NOT run on httpd 16KB stack)
static void save_satellites_nvs_task_(void *) {
  save_satellites_to_nvs_();
  vTaskDelete(nullptr);
}
static void schedule_save_satellites_nvs_() {
  BaseType_t ret = xTaskCreate(save_satellites_nvs_task_, "agg_nvs_save", 8192, nullptr, 1, nullptr);
  if (ret != pdPASS) {
    ESP_LOGE(TAG_AGG, "schedule_save_satellites_nvs_: xTaskCreate failed (ret=%d)", (int)ret);
  }
}
```

> **Note:** The `save_satellites_nvs_task_` / `schedule_save_satellites_nvs_()` scaffold should be placed near the existing `schedule_reset_satellites_()` and `schedule_delete_data_()` functions (around line 1130). The `handle_delete_satellite_()` handler calls `schedule_save_satellites_nvs_()` after sending the response.
