## 4) Exact Scope (§3.5)
Implement `DELETE /api/aggregator/satellite/{id}`:

### 4.1 Request contract
- Method: `DELETE`
- ID source: URL path segment after `/api/aggregator/satellite/`
- Lookup by **satellite ID string**, never by client-provided index

### 4.2 Branch behavior
- 405: wrong method
- 404: unknown satellite ID
- 200: deleted

### 4.3 Mutation algorithm (under mutex)
1. Find matching index by scanning `0..runtime_satellite_count-1`.
2. Shift entries above removed index down by one (dense compaction).
3. Decrement `runtime_satellite_count`.
4. Clear now-vacant tail slot with `clear_cache()`.
5. Persist with `save_satellites_to_nvs_()` that rewrites all index keys from scratch.

### 4.4 Required invariant
After delete, NVS keys must reflect compacted indices only; no stale hole keys remain.

### 4.5 Data-flow trace (mandatory)
```text
DELETE /api/aggregator/satellite/{id}
  → parse id from path
  → scan active runtime list for id
  → lock cache mutex
  → compact array (shift down)
  → decrement runtime_satellite_count
  → clear vacated slot
  → rewrite full agg_sats namespace keys
  → unlock
  → return 200
```
