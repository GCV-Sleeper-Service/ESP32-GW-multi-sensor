## 5. Exact Scope — Dashboard Add/Remove/Test UI

Modify `renderSettingsPanel()` in `dashboard.js` to replace the read-only satellite list with interactive controls. **NO firmware changes in this step. All changes are JS + HTML + dashboard.h regeneration.**

### 5a. UI components to add

The Settings panel gets three new elements:

**1. Add Satellite form** — placed at the top of the settings panel:
- URL text input (`<input type="text" placeholder="http://192.168.x.x">`)
- Optional name text input (`<input type="text" placeholder="Friendly name (optional)">`)
- `Test` button — calls `POST /api/aggregator/test-satellite?url=...`
- `Add` button — calls `POST /api/aggregator/add-satellite?url=...&name=...`
- Inline status area — shows success/error messages; **do not use `alert()`**

**2. Per-satellite remove button** — on each satellite card:
- `Remove` button
- Click triggers `confirm()` dialog: `Remove satellite {name}? This cannot be undone.`
- On confirm: calls `DELETE /api/aggregator/satellite/{id}`
- On success: re-fetches gateway list and re-renders

**3. Enhanced status display** per satellite:
- Last-seen timestamp from `gw.last_seen`
- Consecutive failure count if `> 0`
- Existing online/unreachable indicator preserved

### 5b. Explicit API/Auth Policy Block

This section is mandatory because v7.6.0.3 audit showed that endpoint prompts and UI code must state auth policy explicitly.

| Action | Endpoint | Method | Auth Policy | Body Policy |
|---|---|---|---|---|
| Test satellite | `/api/aggregator/test-satellite?url=...` | POST | **REQUIRED** — use `requestManagementCredentials()` and send `Authorization: Basic ...` | **REQUIRED** — `Content-Type: application/x-www-form-urlencoded`, `body: 'a=1'` |
| Add satellite | `/api/aggregator/add-satellite?...` | POST | **NOT REQUIRED** — follow current firmware contract | **REQUIRED** — `Content-Type: application/x-www-form-urlencoded`, `body: 'a=1'` |
| Remove satellite | `/api/aggregator/satellite/{id}` | DELETE | **REQUIRED** — use `requestManagementCredentials()` and send `Authorization: Basic ...` | No request body required |

**Do not invent new auth policy in this step.** The UI must match the current merged firmware contract.

### 5c. Data flow trace: Test + Add Satellite

```text
User enters URL → clicks Test
  → requestManagementCredentials('satellite test')
  → if cancelled: inline "Test cancelled"
  → if confirmed: POST /api/aggregator/test-satellite?url=...
       with Authorization + form body 'a=1'
  → Display result inline:
      - Success: "✓ Found: {name} ({hardware}, {sensor_count} devices)"
      - Failure: "✗ {error message}"

User clicks Add
  → POST /api/aggregator/add-satellite?url=...&name=...
       with form body 'a=1'
  → On 200: clear form, re-fetch gateways, re-render settings panel
  → On 400/409: display error message inline
```

### 5d. Data flow trace: Remove Satellite

```text
User clicks Remove on satellite card
  → confirm("Remove satellite {name}? This cannot be undone.")
  → requestManagementCredentials('satellite removal')
  → if cancelled: inline "Remove cancelled"
  → if confirmed: DELETE /api/aggregator/satellite/{id}
       with Authorization header
  → On 200: re-fetch gateways, re-render settings panel
  → On 404: display "Satellite not found" inline
```

### 5e. Implementation requirements for `renderSettingsPanel()`

Replace the **entire body** of `renderSettingsPanel(gateways)` with the new interactive version.

#### Dynamic-text safety
Use `escHtml()` on **all** dynamic text inserted into HTML:
- `gw.name`
- `gw.id`
- `gw.base_url`
- `gw.firmware_version`
- `gw.hardware`
- any returned test-satellite values shown via `innerHTML`

Use `escAttr()` for any dynamic text inserted into attribute values:
- `data-sat-id`
- `data-sat-name`
- any other custom `data-*` attributes

#### Event binding
Use **programmatic** event binding after `innerHTML` is assigned. No inline `onclick`, `oninput`, `onchange`.

#### Null checks
Use explicit checks (`!== undefined && !== null`), never truthy checks on values that may legitimately be `0`, especially:
- `gw.last_seen`
- `gw.consecutive_failures`
- `gw.sensor_count`
- `gw.device_count`

#### In-flight / duplicate action handling
This step introduces user-triggered network actions. Guard against duplicate requests:
- disable the clicked button while a request is in flight, **or**
- use a small module-level in-flight flag per action

Do **not** allow rapid double-clicks to queue duplicate add/remove/test requests.

#### Theme compatibility
All new `<input>` and `<button>` elements must support dark/light mode:
```css
color-scheme: light dark;
```

### 6a. `renderSettingsPanel(gateways)` skeleton

```javascript
function renderSettingsPanel(gateways) {
  var grid = document.getElementById('gwGrid');
  if (!grid) return;

  var html = '<div class="settings-panel">';
  html += '<h3 class="settings-title">Satellite Management</h3>';

  html += '<div class="settings-add-form" id="add-sat-form">';
  html += '<div class="settings-add-row">';
  html += '<input type="text" id="add-sat-url" class="settings-input" placeholder="http://192.168.x.x">';
  html += '<input type="text" id="add-sat-name" class="settings-input settings-input-name" placeholder="Name (optional)">';
  html += '</div>';
  html += '<div class="settings-add-actions">';
  html += '<button id="test-sat-btn" class="settings-btn settings-btn-test">Test</button>';
  html += '<button id="add-sat-btn" class="settings-btn settings-btn-add">Add</button>';
  html += '</div>';
  html += '<div id="add-sat-status" class="settings-status"></div>';
  html += '</div>';

  if (!gateways || gateways.length === 0) {
    html += '<p class="settings-empty">No satellites configured.</p>';
  } else {
    gateways.forEach(function(gw) {
      var fwVersion = (gw.firmware_version !== undefined && gw.firmware_version !== null) ? gw.firmware_version : '—';
      var deviceCount = '—';
      if (gw.device_count !== undefined && gw.device_count !== null) deviceCount = gw.device_count;
      else if (gw.sensor_count !== undefined && gw.sensor_count !== null) deviceCount = gw.sensor_count;

      html += '<div class="settings-satellite-card">';
      html += '<div class="settings-sat-header">' +
        (gw.reachable ? '🟢 ' : '🔴 ') + escHtml(gw.name || gw.id || 'Unknown') +
        ' <span class="settings-sat-id">(' + escHtml(gw.id || '—') + ')</span></div>';
      html += '<div class="settings-sat-details">';
      html += '<div>URL: <code>' + escHtml(gw.base_url || '—') + '</code></div>';
      html += '<div>Firmware: ' + escHtml(String(fwVersion)) + '</div>';
      html += '<div>Devices: ' + escHtml(String(deviceCount)) + '</div>';
      html += '<div>Status: ' + (gw.reachable ? 'Online' : 'Unreachable') + '</div>';

      if (gw.last_seen !== undefined && gw.last_seen !== null && gw.last_seen > 0) {
        html += '<div>Last seen: ' + escHtml(new Date(gw.last_seen * 1000).toLocaleString()) + '</div>';
      }
      if (gw.consecutive_failures !== undefined && gw.consecutive_failures !== null && gw.consecutive_failures > 0) {
        html += '<div class="settings-warning">⚠ ' + escHtml(String(gw.consecutive_failures)) + ' consecutive failure(s)</div>';
      }
      html += '</div>';
      html += '<button class="settings-btn settings-btn-remove" data-sat-id="' + escAttr(gw.id || '') +
        '" data-sat-name="' + escAttr(gw.name || gw.id || 'satellite') + '">Remove</button>';
      html += '</div>';
    });
  }

  html += '</div>';
  grid.innerHTML = html;

  var testBtn = document.getElementById('test-sat-btn');
  if (testBtn) testBtn.addEventListener('click', _handleTestSatellite);

  var addBtn = document.getElementById('add-sat-btn');
  if (addBtn) addBtn.addEventListener('click', _handleAddSatellite);

  document.querySelectorAll('.settings-btn-remove').forEach(function(btn) {
    btn.addEventListener('click', function() {
      _handleRemoveSatellite(
        btn.getAttribute('data-sat-id'),
        btn.getAttribute('data-sat-name')
      );
    });
  });
}
```

### 6c. Handler functions

#### `_handleTestSatellite()`
Must:
1. read URL input
2. request management credentials
3. send `POST` with auth + form body `a=1`
4. parse with `safeJsonResponse()`
5. show inline success/error state

Representative shape:

```javascript
function _handleTestSatellite() {
  var urlInput = document.getElementById('add-sat-url');
  var statusDiv = document.getElementById('add-sat-status');
  if (!urlInput || !statusDiv) return;

  var url = String(urlInput.value || '').trim();
  if (!url) {
    statusDiv.textContent = 'Enter a URL first.';
    return;
  }

  statusDiv.textContent = 'Authenticating for test...';
  requestManagementCredentials('satellite test').then(function(creds) {
    if (!creds) {
      statusDiv.textContent = 'Test cancelled';
      return null;
    }
    statusDiv.textContent = 'Testing...';
    return fetch(ESP_HOST + '/api/aggregator/test-satellite?url=' + encodeURIComponent(url), {
      method: 'POST',
      cache: 'no-store',
      headers: {
        'Authorization': 'Basic ' + btoa(creds.username + ':' + creds.password),
        'Content-Type': 'application/x-www-form-urlencoded'
      },
      body: 'a=1'
    }).then(safeJsonResponse);
  }).then(function(data) {
    if (!data) return;
    if (data.ok && data.gateway) {
      var gw = data.gateway;
      statusDiv.innerHTML = '✓ Found: <strong>' + escHtml(gw.name || gw.id || 'Unknown') +
        '</strong> (' + escHtml(gw.hardware || '?') + ', ' +
        escHtml(String((gw.sensor_count !== undefined && gw.sensor_count !== null) ? gw.sensor_count : '?')) +
        ' devices)';
    } else {
      statusDiv.textContent = '✗ ' + (data.message || 'Test failed');
    }
  }).catch(function(err) {
    statusDiv.textContent = '✗ ' + err.message;
  });
}
```

#### `_handleAddSatellite()`
Must:
- send POST with form body `a=1`
- no auth header
- use `safeJsonResponse()`
- clear form on success
- re-fetch settings panel immediately on success

#### `_handleRemoveSatellite(satId, satName)`
Must:
- confirm first
- request management credentials
- send DELETE with Authorization header
- use `safeJsonResponse()`
- re-fetch settings panel on success

### 6d. `_refreshSettingsPanel()`
Use a single, simple re-fetch of `/api/aggregator/gateways`:

```javascript
function _refreshSettingsPanel() {
  return fetch(ESP_HOST + '/api/aggregator/gateways', {cache: 'no-store'})
    .then(safeJsonResponse)
    .then(function(data) {
      if (data && data.gateways) {
        window._aggregatorGateways = data.gateways;
        renderSettingsPanel(data.gateways);
      }
      return data;
    });
}
```
