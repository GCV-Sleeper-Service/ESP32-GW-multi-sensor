## 4) Exact Scope (§3.5)
Implement `POST /api/aggregator/test-satellite`:

### 4.1 Request contract
- Method: `POST`
- Query param: `url` (required)
- Example: `POST /api/aggregator/test-satellite?url=http://192.168.1.42`

### 4.2 Probe implementation
- Reuse probe logic from v7.6.0.1.
- If shared helper does not exist, factor a helper now (`probe_satellite_manifest_()` suggested) used by both add and test handlers.
- Probe target: `url + "/api/manifest"`.

### 4.3 Response behavior
- 400: missing URL
- 400: probe failed/unreachable/invalid manifest
- 200: include summary fields from manifest gateway payload:
  - `id`
  - `name`
  - `hardware`
  - `sensor_count`

### 4.4 Side-effect prohibition
- Must **not** modify `satellite_caches[]`
- Must **not** modify `runtime_satellite_count`
- Must **not** write NVS

### 4.5 Data-flow trace
```text
POST test-satellite(url)
  → validate url
  → probe url/api/manifest
  → parse gateway summary fields
  → return summary (200)
(no runtime list mutation, no NVS writes)
```
