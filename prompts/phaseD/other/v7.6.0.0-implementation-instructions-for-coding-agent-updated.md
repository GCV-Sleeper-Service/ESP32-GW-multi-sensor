## 4) Exact Scope (§3.5)
### 4.1 Add runtime persistence primitives
In `dashboard/sensor_history_multi.h`, implement:
- `static int runtime_satellite_count`
- `load_satellites_from_nvs_()`
- `save_satellites_to_nvs_()`
- `save_single_satellite_to_nvs_()` (available for future use, but full-save remains canonical for list mutation integrity)

### 4.2 NVS schema (fixed)
Namespace `agg_sats`:
- `count` (u8)
- `s0_id/s0_name/s0_url/s0_poll` … `sN_*`

### 4.3 Hybrid hardening import (from CL)
If `SatelliteCache` uses `const char*` identity fields, add owned buffers and an identity setter to prevent pointer aliasing issues after NVS loads and compaction moves.
- Example buffers: `id_buf`, `name_buf`, `url_buf`
- Ensure `id/name/base_url` pointers always reference storage owned by the same struct slot.

### 4.4 Boot path behavior
- On boot: try NVS first.
- If namespace empty/missing/corrupt: compile-time fallback arrays from `aggregator_config.h`.
- Set `runtime_satellite_count` from active source.
- Keep unified boot path (LESSON-OPS-074).

### 4.5 Loop-bound migration
Replace runtime iteration bounds `MAX_SATELLITES` → `runtime_satellite_count` in all active-satellite loops.
Use `MAX_SATELLITES` only as capacity guard.

### 4.6 Reset endpoint
Implement:
- `POST /api/system/reset-satellites`
- Clear `agg_sats`
- Reload compile-time defaults into runtime cache for current boot
- Leave NVS empty after reset clear (no repopulation in reset handler)

### 4.7 Mandatory data lifecycle trace
```text
Boot → load_satellites_from_nvs_() → populate satellite_caches[] → set runtime_satellite_count
  ↓ (if NVS empty/corrupt)
Boot → copy compile-time arrays → populate satellite_caches[] → set runtime_satellite_count
  ↓
Poll task iterates 0..runtime_satellite_count-1
  ↓
All API handlers iterate 0..runtime_satellite_count-1
```

## 7) Runtime Mutation Safety Checklist
### Runtime Mutation Safety Checklist
- [ ] All satellite iteration loops use `runtime_satellite_count`, not `MAX_SATELLITES`
- [ ] All cache mutations (add/remove/clear) happen under `s_cache_mutex` (AGG_LOCK/AGG_UNLOCK)
- [ ] No code caches a satellite array index across function calls or requests
- [ ] Boot path remains unified: satellite boot + aggregator overlay, not a fork (LESSON-OPS-074)
- [ ] NVS empty/fallback path verified (first boot or corrupted namespace → compile-time defaults)
- [ ] NVS write errors logged but do not crash or corrupt runtime state
- [ ] Array compaction after delete tested (v7.6.0.2+)
