## 4) Exact Scope (§3.5)
### 4.1 Endpoint contract
`DELETE /api/aggregator/satellite/{id}`
- Parse ID from URL path.
- Find by ID scan (never by user index).

### 4.2 Branches
- 405 wrong method
- 404 unknown ID
- 200 success

### 4.3 Compaction algorithm (hybrid hardening)
Under mutex:
1. Find `del_idx` in `0..runtime_satellite_count-1`.
2. Shift entries `[del_idx+1 .. end]` down.
3. Decrement `runtime_satellite_count`.
4. Clear vacated tail slot.
5. Persist via `save_satellites_to_nvs_()` full rewrite.

Hardening note: avoid blind struct-level copy if struct contains pointer fields; preserve pointer-to-owned-buffer correctness per slot.

### 4.4 Data flow trace
```text
DELETE /api/aggregator/satellite/{id}
  → parse id
  → scan runtime list
  → lock mutex
  → compact array
  → decrement runtime_satellite_count
  → clear vacated slot
  → full NVS rewrite
  → unlock
  → return 200
```
