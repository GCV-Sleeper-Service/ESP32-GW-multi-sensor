## 4) Exact Scope (§3.5)
### 4.1 Endpoint contract
`POST /api/aggregator/add-satellite?url=http://...&name=Kitchen&poll=30`
- Query-string only (no JSON body parsing)

### 4.2 Validation branches (contract-locked)
- 405 wrong method
- 400 missing URL
- 400 invalid URL format (`http://` required)
- 409 list full (`runtime_satellite_count >= MAX_SATELLITES`)
- 409 duplicate URL
- 400 probe failed / invalid manifest
- 200 success

### 4.3 Probe logic
- Probe `url + "/api/manifest"` via `fetch_to_buffer`.
- Extract `gateway.id` + `gateway.name`.
- Hybrid hardening import: if multiple buffers exist, use web-handler-safe buffer for handler context (avoid poll-task-only temporary buffer).

### 4.4 Mutation + persistence
Under `AGG_LOCK()`:
1. Append into `satellite_caches[runtime_satellite_count]`.
2. Initialize identity + poll + cache fields.
3. Increment `runtime_satellite_count`.
4. Persist using `save_satellites_to_nvs_()` full rewrite (do not use single-save in this endpoint).

On NVS write error: log + return error without corrupting list state.

### 4.5 Data flow trace
```text
POST add-satellite(url,name,poll)
  → validate query
  → probe manifest
  → derive satellite metadata
  → lock mutex
  → append new slot
  → increment runtime_satellite_count
  → full-save NVS
  → unlock
  → return 200 summary
```

## 7) Runtime Mutation Safety Checklist
### Runtime Mutation Safety Checklist
- [ ] All satellite iteration loops use `runtime_satellite_count`, not `MAX_SATELLITES`
- [ ] All cache mutations (add/remove/clear) happen under `s_cache_mutex` (AGG_LOCK/AGG_UNLOCK)
- [ ] No code caches a satellite array index across function calls or requests
- [ ] Boot path remains unified: satellite boot + aggregator overlay, not a fork (LESSON-OPS-074)
- [ ] NVS empty/fallback path verified (first boot or corrupted namespace → compile-time defaults)
- [ ] NVS write errors logged but do not crash or corrupt runtime state
- [ ] Array compaction after delete tested (v7.6.0.2+)
- [ ] Poll task behavior verified during/after add/remove operations
