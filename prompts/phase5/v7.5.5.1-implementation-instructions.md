## Exact scope

Implement background aggregator polling task.

1. Add `SatelliteCache` struct (~7KB per satellite: 4K manifest + 2K live + 512 status)
2. Add `AggregatorTask` RTOS task — polls satellites sequentially with staggered timing
3. Fetch cycle: /api/manifest (every 5min), /api/status + /api/v2/live (every poll_interval)
4. Mark satellite unreachable after 3 consecutive failures
5. Use `esp_http_client.h` with 5s connection timeout
6. Conditionally start task when role is aggregator
7. Satellite firmware (no aggregator.json) completely unaffected

**⚠️ HIGH RISK — new RTOS task, HTTP client, memory management.**
Requires two ESP32 devices for testing (one satellite, one aggregator).
