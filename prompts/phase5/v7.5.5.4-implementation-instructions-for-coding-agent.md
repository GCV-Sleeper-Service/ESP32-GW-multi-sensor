## 5. Exact Scope — Aggregator Test Fixtures + Playwright Tests

### 5a. Create `tests/fixtures/variants/aggregator/` directory

This fixture set simulates an aggregator with 2 satellites: one reachable, one unreachable.

| File | Content |
|------|---------|
| `sensors.json` | v1 projection for aggregator's own local sensors (can be minimal — 1 sensor) |
| `manifest.json` | v2 manifest for the aggregator device itself |
| `api-status.json` | Aggregator gateway status |
| `storage-stats.json` | Storage stats |
| `aggregator-gateways.json` | **Key fixture:** mock `/api/aggregator/gateways` response |
| `aggregator-live.json` | **Key fixture:** mock `/api/aggregator/live` response |
| History CSV files for proxied requests |

**`aggregator-gateways.json`** — two satellites, mixed reachability:

```json
{
  "gateways": [
    {
      "id": "gw-main",
      "name": "Main Gateway",
      "reachable": true,
      "last_seen": 1710264000,
      "consecutive_failures": 0,
      "manifest_cached": true,
      "live_cached": true
    },
    {
      "id": "gw-garage",
      "name": "Garage Sensors",
      "reachable": false,
      "last_seen": 1710260000,
      "consecutive_failures": 5,
      "manifest_cached": true,
      "live_cached": false
    }
  ]
}
```

**`aggregator-live.json`** — unified live data:

```json
{
  "timestamp": 1710264000,
  "gateways": {
    "gw-main": {
      "reachable": true,
      "live": "{\"timestamp\":1710264000,\"devices\":{\"office\":{\"temp\":23.4,\"hum\":45.2,\"batt\":87,\"rssi\":-62,\"last_seen\":1710263985},\"wan_ping\":{\"ping_ms\":12.3,\"success_pct\":100.0,\"last_seen\":1710263990}}}"
    },
    "gw-garage": {
      "reachable": false,
      "live": null
    }
  }
}
```

Note: The `live` field is a JSON string (raw cached response from satellite). The dashboard parses it.

Also create proxy-compatible history fixtures:
- `history-gw-main-office-temp.csv` — standard epoch,value CSV
- `history-gw-main-office-hum.csv`

### 5b. Extend `tests/mock-server/server.js` for aggregator mode

Add routes that activate when `FIXTURE_SET=aggregator`:

```js
// Aggregator endpoints (only when FIXTURE_SET=aggregator)
if (process.env.FIXTURE_SET === 'aggregator') {
  app.get('/api/aggregator/gateways', (req, res) => {
    const fixture = loadFixture('aggregator-gateways.json');
    res.json(fixture);
  });
  
  app.get('/api/aggregator/live', (req, res) => {
    const fixture = loadFixture('aggregator-live.json');
    res.json(fixture);
  });
  
  app.get('/api/aggregator/proxy/:gwId/history/:device/:metric', (req, res) => {
    const { gwId, device, metric } = req.params;
    const filename = `history-${gwId}-${device}-${metric}.csv`;
    try {
      const csv = loadFixtureText(filename);
      res.type('text/plain').send(csv);
    } catch(e) {
      res.status(404).send('Not found');
    }
  });
}

// When NOT aggregator fixture set, /api/aggregator/gateways returns 404
// (this is what makes satellite-mode detection work)
if (process.env.FIXTURE_SET !== 'aggregator') {
  app.get('/api/aggregator/gateways', (req, res) => {
    res.status(404).send('Not found');
  });
}
```

**Critical:** When `FIXTURE_SET` is NOT `aggregator`, the `/api/aggregator/gateways` endpoint must return 404. This ensures satellite-mode dashboard tests work correctly — `detectAggregatorMode()` sees 404 and stays in satellite mode.

### 5c. Add Playwright test Group 18: Aggregator Mode

Verify the actual next group number by checking `dashboard.spec.js`. Add:

```js
// ── 18. Aggregator Mode (Phase 5) ──────────────────────────────
test.describe('18. Aggregator Mode', () => {

  test('aggregator mode detected when /api/aggregator/gateways returns 200', async ({ page }) => {
    await page.goto('/', { waitUntil: 'domcontentloaded' });
    // Wait for aggregator mode initialization
    await page.waitForFunction(() => {
      return typeof window.DASHBOARD_MODE !== 'undefined' && window.DASHBOARD_MODE === 'aggregator';
    }, { timeout: 15000 });
    const mode = await page.evaluate(() => window.DASHBOARD_MODE);
    expect(mode).toBe('aggregator');
  });

  test('gateway selector bar is visible in aggregator mode', async ({ page }) => {
    await page.goto('/', { waitUntil: 'domcontentloaded' });
    await page.waitForSelector('#gwSelector', { timeout: 15000 });
    const selector = page.locator('#gwSelector');
    await expect(selector).toBeVisible();
  });

  test('gateway selector has correct number of tabs', async ({ page }) => {
    await page.goto('/', { waitUntil: 'domcontentloaded' });
    await page.waitForSelector('#gwSelector', { timeout: 15000 });
    // "All Gateways" + 2 satellite tabs = 3 tabs
    const tabs = page.locator('.gw-tab');
    await expect(tabs).toHaveCount(3);
  });

  test('unreachable satellite shown as offline', async ({ page }) => {
    await page.goto('/', { waitUntil: 'domcontentloaded' });
    await page.waitForSelector('#gwSelector', { timeout: 15000 });
    const offlineTab = page.locator('.gw-tab.gw-offline');
    await expect(offlineTab).toHaveCount(1);
  });

  test('All Gateways summary renders gateway status cards', async ({ page }) => {
    await page.goto('/', { waitUntil: 'domcontentloaded' });
    await page.waitForSelector('.gw-summary-card', { timeout: 15000 });
    const summaryCards = page.locator('.gw-summary-card');
    await expect(summaryCards).toHaveCount(2);  // 2 gateways
  });

  test('clicking a gateway tab shows its device cards', async ({ page }) => {
    await page.goto('/', { waitUntil: 'domcontentloaded' });
    await page.waitForSelector('#gwSelector', { timeout: 15000 });
    // Click on "Main Gateway" tab
    await page.locator('.gw-tab[data-gw="gw-main"]').click();
    // Should show device cards (wait for rendering)
    await page.waitForSelector('.sensor-card', { timeout: 10000 });
    const cards = page.locator('.sensor-card');
    const count = await cards.count();
    expect(count).toBeGreaterThan(0);
  });

  test('satellite mode fallback — no aggregator UI when gateways returns 404', async ({ page }) => {
    // This test runs with root baseline fixtures (no aggregator endpoints)
    // The mock server returns 404 for /api/aggregator/gateways
    // Dashboard should be in satellite mode
    await loadDashboard(page);
    const gwSelector = page.locator('#gwSelector');
    await expect(gwSelector).toHaveCount(0);
    const mode = await page.evaluate(() => window.DASHBOARD_MODE || 'satellite');
    expect(mode).toBe('satellite');
  });

});
```

**Important:** Test 7 (satellite fallback) works with the ROOT fixture set (not aggregator) because the mock server returns 404 for `/api/aggregator/gateways` when `FIXTURE_SET` is not `aggregator`. This test should be in the root baseline suite.

Actually, reconsider: Group 18 tests that require `FIXTURE_SET=aggregator` should be isolated. Test 7 (satellite fallback) can stay in the root baseline since it tests the 404 path.

**Recommended approach:** Put tests 1–6 in Group 18 (aggregator-specific, requires `FIXTURE_SET=aggregator`). Put test 7 as an additional test in Group 14 or a new satellite-mode guard test, since it runs with root fixtures.
