## Exact scope

Create aggregator test fixtures and add Playwright tests for aggregator mode.

### Step-by-step:

1. **Create `tests/fixtures/variants/aggregator/` directory:**
   - `manifest.json` — v2 manifest for the aggregator device itself
   - `sensors.json` — v1 projection
   - `api-status.json` — aggregator status
   - `aggregator-gateways.json` — mock response for `/api/aggregator/gateways` (2 satellites: 1 reachable, 1 unreachable)
   - `aggregator-live.json` — mock response for `/api/aggregator/live` (unified live data from both satellites)
   - History fixtures for proxied requests

2. **Extend `tests/mock-server/server.js`:**
   - Add `/api/aggregator/gateways` route — serve `aggregator-gateways.json` fixture
   - Add `/api/aggregator/live` route — serve `aggregator-live.json` fixture
   - Add `/api/aggregator/proxy/:gwId/history/:device/:metric` — proxy to standard history fixtures
   - These routes active only when `FIXTURE_SET=aggregator`

3. **Add Playwright test Group 18: Aggregator Mode** to `dashboard.spec.js`:
   ```
   Test 1: Aggregator mode detected when /api/aggregator/gateways returns 200
   Test 2: Gateway selector bar is visible in aggregator mode
   Test 3: "All Gateways" summary renders gateway cards with status
   Test 4: Unreachable satellite shown as offline/grayed
   Test 5: Selecting a gateway shows its device cards
   Test 6: Device cards use correct CARD_RENDERERS per category
   Test 7: History charts load through aggregator proxy
   Test 8: Satellite mode fallback — no aggregator UI when /api/aggregator/gateways returns 404
   ```

   Run with `FIXTURE_SET=aggregator` for aggregator tests.

4. **Update changelog, session log, bump to 7.5.5.4**

### Test execution:

```bash
# Root baseline (satellite mode — all existing tests):
```
