#### ⚠️ MANDATORY FIXTURE FORMATTING RULES (learned from 3 CI failures in v7.5.5.3)

These rules apply to **every JSON file** you create or modify in this step:

1. **Real newlines only** — JSON fixture files MUST use actual newline characters (`\n`). Do NOT write a JSON string with `\n` as two characters (backslash + n). If using a script or API to create the file, ensure the content is properly decoded before writing. Verify with `cat -A file.json` — there should be `$` at end of each line, not literal `\n`.

2. **Trailing newline required** — Every JSON fixture file MUST end with a single newline character after the closing `}`. Most POSIX tools (including `render_sensor_config.py --write`) produce files with a trailing newline. Omitting it causes the preflight sync check to fail.

3. **`api-status.json` MUST include heap fields** — BUG-062: the heap fields were missing and caused CI failures. Every `api-status.json` (root, variant, and aggregator) must have:
   ```json
   "free_heap": 81920,
   "free_heap_internal": 81920,
   "free_heap_total": 81920
   ```

4. **After creating/modifying any fixture, run the sync check:**
   ```bash
   python3 scripts/render_sensor_config.py --check
   ```
   If this fails with "Generated files are out of sync", run:
   ```bash
   python3 scripts/render_sensor_config.py --write
   ```
   Then commit the regenerated files. **Do not skip this step.**

5. **Valid JSON** — validate all JSON files before committing:
   ```bash
   python3 -m json.tool tests/fixtures/variants/aggregator/api-status.json > /dev/null
   python3 -m json.tool tests/fixtures/variants/aggregator/aggregator-gateways.json > /dev/null
   python3 -m json.tool tests/fixtures/variants/aggregator/aggregator-live.json > /dev/null
   ```

### 5b. Extend `tests/mock-server/server.js` for aggregator mode

#### ⚠️ CRITICAL: Extend the existing route — do NOT create a duplicate

The mock server (`tests/mock-server/server.js`) **already has** an `/api/aggregator/gateways` route (added by v7.5.5.3). It currently returns `{"gateways":[]}` (200 OK, empty array) for all fixture sets:

```js
// Current code (around line 234) — DO NOT DUPLICATE THIS:
if (pathname === '/api/aggregator/gateways') {
  return json(res, { gateways: [] });
}
```

The empty array is what causes `detectAggregatorMode()` to remain in satellite mode — it checks `data.gateways.length > 0`. When `FIXTURE_SET=aggregator`, the route must return the fixture file instead.

**How to extend it:**

Replace the existing `if (pathname === '/api/aggregator/gateways')` block with:

```js
if (pathname === '/api/aggregator/gateways') {
  const gwFixture = loadFixture('aggregator-gateways.json');
  if (gwFixture) {
    return json(res, JSON.parse(gwFixture));
  }
  return json(res, { gateways: [] });
}
```

This works because:
- When `FIXTURE_SET=aggregator`, `loadFixture('aggregator-gateways.json')` finds `tests/fixtures/variants/aggregator/aggregator-gateways.json` and returns the 2-gateway list.
- When `FIXTURE_SET` is anything else (root, 3sensor, mixed), `loadFixture` returns `null` (file doesn't exist in those variant directories), and the fallback `{gateways:[]}` is returned — keeping satellite mode behavior.

Similarly, extend the `/api/aggregator/live` route:

```js
if (pathname === '/api/aggregator/live') {
  const liveFixture = loadFixture('aggregator-live.json');
  if (liveFixture) {
    return json(res, JSON.parse(liveFixture));
  }
  return json(res, { timestamp: Math.floor(Date.now() / 1000), gateways: {} });
}
```

And the proxy route:

```js
if (pathname.startsWith('/api/aggregator/proxy/')) {
  // pathname: /api/aggregator/proxy/{gwId}/history/{device}/{metric}
  const parts = pathname.split('/');
  // parts: ['', 'api', 'aggregator', 'proxy', gwId, 'history', device, metric]
  if (parts.length >= 8 && parts[5] === 'history') {
    const gwId = parts[4];
    const device = parts[6];
    const metric = parts[7];
    const csvFile = `history-${gwId}-${device}-${metric}.csv`;
    const csv = loadFixture(csvFile);
    if (csv) {
      res.writeHead(200, { 'Content-Type': 'text/plain', 'Access-Control-Allow-Origin': '*' });
      return res.end(csv);
    }
  }
  return notFound(res, pathname);
}
```

**Do NOT add `if (FIXTURE_SET === 'aggregator')` guards** — the `loadFixture()` function already handles variant fallback. Adding explicit guards creates fragile coupling and breaks the fallback pattern used everywhere else.
