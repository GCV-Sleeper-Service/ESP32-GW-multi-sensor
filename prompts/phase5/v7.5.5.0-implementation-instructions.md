## Exact scope

Define aggregator configuration schema and loader. **No runtime changes.** Configuration schema only.

### Step-by-step:

1. **Create `config/aggregator.example.json`** — Example configuration with 2 satellite entries:
   ```json
   {
     "schema_version": 1,
     "role": "aggregator",
     "satellites": [
       {
         "id": "gw-main",
         "name": "Main Gateway",
         "base_url": "http://192.168.10.20",
         "poll_interval_seconds": 30,
         "auth": null
       },
       {
         "id": "gw-garage",
         "name": "Garage Sensors",
         "base_url": "http://192.168.10.21",
         "poll_interval_seconds": 30,
         "auth": { "type": "basic", "username": "admin", "password_ref": "secrets.garage_pw" }
       }
     ]
   }
   ```

2. **Add `load_aggregator_config()` and `validate_aggregator_config()` to `sensor_manifest_lib.py`:**
   - Load from `config/aggregator.json` (separate from `config/sensors.json`)
   - Validate: unique satellite IDs, valid HTTP/HTTPS URLs, `poll_interval_seconds` range 10–300
   - Return `None` if file doesn't exist (satellite mode — no aggregator)
   - `password_ref` should reference a key in secrets (validated at generation time if possible)

3. **Conditionally generate aggregator config header** in `render_sensor_config.py`:
   - If `config/aggregator.json` exists: generate `src/aggregator_config.h` with satellite URLs and IDs as C string constants
   - If `config/aggregator.json` does NOT exist: skip generation, satellite firmware is unaffected
   - Add a `#define AGGREGATOR_ENABLED 1` or `0` flag

4. **Update preflight:**
   - If `config/aggregator.json` exists: validate schema
   - If absent: skip aggregator checks (no failure)

5. **Update changelog, session log, bump to 7.5.5.0**

### Critical constraints:
- Satellite firmware must be COMPLETELY UNAFFECTED when `config/aggregator.json` is absent
- This step is schema/tooling only — no RTOS tasks, no HTTP clients, no runtime code
- The `sensors.json` and `aggregator.json` are separate files serving different concerns (per architecture plan Section 8.2)
