## 5. Platform Considerations

### ESP32-S3 vs ESP32-C3 for aggregator

The architecture plan recommends ESP32-S3 for aggregation. However, the current firmware and YAML are ESP32-C3 specific. For the MVP:

**Use the same ESP32-C3 YAML and firmware for both roles.** The aggregator code compiles into the same binary, activated by `#if AGGREGATOR_ENABLED`. This keeps one codebase.

**Limitation:** The C3 (320KB RAM, single-core) can support 1–2 satellites max. For more satellites, an S3-specific YAML variant would be needed in a future step.

**BLE scanner on aggregator:** The aggregator device still runs the BLE scanner for its own local sensors (defined in `sensors.json`). The BLE scanner and aggregator polling task coexist. The polling task runs at low priority and yields between requests. On the C3, this means the polling cycle takes longer (sequential everything), but it works.

## 6. Exact Scope — Aggregator Polling Task

Implement the background task that polls satellite APIs and caches results in RAM.

### 6a. Add `SatelliteCache` struct

Add to `dashboard/sensor_history_multi.h` inside an `#if AGGREGATOR_ENABLED` block:

```cpp
#if AGGREGATOR_ENABLED

struct SatelliteCache {
  const char* id;
  const char* name;
  const char* base_url;
  int poll_interval_seconds;
  
  // Cached responses (statically allocated — no malloc)
  char manifest_json[4096];     // cached /api/manifest response
  char live_json[2048];         // cached /api/v2/live response
  char status_json[512];        // cached /api/status response
  uint16_t manifest_len;
  uint16_t live_len;
  uint16_t status_len;
  
  // State
  uint32_t last_manifest_fetch;
  uint32_t last_live_fetch;
  uint32_t last_status_fetch;
  bool reachable;
  uint32_t last_seen_epoch;
  uint8_t consecutive_failures;
  
  void clear_cache() {
    manifest_json[0] = '\0'; manifest_len = 0;
    live_json[0] = '\0'; live_len = 0;
    status_json[0] = '\0'; status_len = 0;
    reachable = false;
    consecutive_failures = 0;
    last_manifest_fetch = 0;
    last_live_fetch = 0;
    last_status_fetch = 0;
    last_seen_epoch = 0;
  }
};

static SatelliteCache satellite_caches[MAX_SATELLITES];

#endif // AGGREGATOR_ENABLED
```

**⚠️ Pointer Lifetime:** Initialize `SatelliteCache` entries from the generated `aggregator_config.h` constants. Point `id` to `SATELLITE_IDS[i]`, `name` to `SATELLITE_NAMES[i]`, `base_url` to `SATELLITE_URLS[i]`. These are string literals with static lifetime — safe to store as `const char*`. DO NOT copy strings into local char arrays and then store pointers to them — this creates dangling references.

**⚠️ Thread Safety (CRITICAL):** The `SatelliteCache` structs are written by the polling task (RTOS task context) and read by HTTP request handlers (ESPHome loop context). Without mutual exclusion, the web handler can read a partially-updated `manifest_json` buffer mid-write.

Add a FreeRTOS mutex:

```cpp
static SemaphoreHandle_t s_cache_mutex = nullptr;

// Call once during init:
static void init_aggregator_mutex() {
  s_cache_mutex = xSemaphoreCreateMutex();
}

// Polling task: take mutex before updating cache, give after
#define AGG_LOCK()   xSemaphoreTake(s_cache_mutex, pdMS_TO_TICKS(200))
#define AGG_UNLOCK() xSemaphoreGive(s_cache_mutex)

// Web handlers: take mutex before reading cache, give after
// Use timeout of 100ms — if lock unavailable, serve stale data rather than blocking
```

**Memory budget per satellite:** ~6.6KB (4096 + 2048 + 512 + overhead). For 2 satellites: ~13.2KB. On C3 with ~60KB free heap (after BLE/WiFi/dashboard): tight but feasible for 1–2 satellites.

### 6b. Add `aggregator_poll_task()` function

```cpp
#if AGGREGATOR_ENABLED

#include <esp_http_client.h>

static bool fetch_to_buffer(const char* url, char* buf, uint16_t buf_size, uint16_t* out_len) {
  esp_http_client_config_t config = {};
  config.url = url;
  config.timeout_ms = 5000;
  config.method = HTTP_METHOD_GET;
  
  esp_http_client_handle_t client = esp_http_client_init(&config);
  if (!client) return false;
  
  esp_err_t err = esp_http_client_open(client, 0);
  if (err != ESP_OK) {
    esp_http_client_cleanup(client);
    return false;
  }
  
  int content_length = esp_http_client_fetch_headers(client);
  int status = esp_http_client_get_status_code(client);
  if (status != 200 || content_length < 0) {
    esp_http_client_close(client);
    esp_http_client_cleanup(client);
    return false;
  }
  
  int read_len = esp_http_client_read(client, buf, buf_size - 1);
  if (read_len >= 0) {
    buf[read_len] = '\0';
    *out_len = (uint16_t)read_len;
  }
  
  esp_http_client_close(client);
  esp_http_client_cleanup(client);
  return read_len > 0;
}

static void aggregator_poll_task(void* arg) {
  // Initialize caches
  for (int i = 0; i < MAX_SATELLITES; i++) {
    satellite_caches[i].id = SATELLITE_IDS[i];
    satellite_caches[i].name = SATELLITE_NAMES[i];
    satellite_caches[i].base_url = SATELLITE_URLS[i];
    satellite_caches[i].poll_interval_seconds = SATELLITE_POLL_INTERVALS[i];
    satellite_caches[i].clear_cache();
  }
  
  // Initial delay — wait for WiFi and local boot to settle
  vTaskDelay(pdMS_TO_TICKS(10000));
  
  char url_buf[256];
  
  while (true) {
    for (int i = 0; i < MAX_SATELLITES; i++) {
      auto& sat = satellite_caches[i];
      uint32_t now = ::time(nullptr);
      
      // Determine poll interval: normal or reduced (for unreachable satellites)
      int interval = sat.reachable ? sat.poll_interval_seconds : 300; // 5 min for unreachable
      
      if (now - sat.last_live_fetch < (uint32_t)interval) {
        continue; // not time yet
      }
      
      bool any_success = false;
      
      // 1. Manifest (cached aggressively — refresh every 5 minutes)
      if (now - sat.last_manifest_fetch > 300 || sat.manifest_len == 0) {
        snprintf(url_buf, sizeof(url_buf), "%s/api/manifest", sat.base_url);
        if (fetch_to_buffer(url_buf, sat.manifest_json, sizeof(sat.manifest_json), &sat.manifest_len)) {
          sat.last_manifest_fetch = now;
          any_success = true;
          ESP_LOGI(TAG, "Satellite %s: manifest cached (%u bytes)", sat.id, sat.manifest_len);
        }
        vTaskDelay(pdMS_TO_TICKS(200)); // yield between requests
      }
      
      // 2. Status
      snprintf(url_buf, sizeof(url_buf), "%s/api/status", sat.base_url);
      if (fetch_to_buffer(url_buf, sat.status_json, sizeof(sat.status_json), &sat.status_len)) {
        sat.last_status_fetch = now;
        any_success = true;
      }
      vTaskDelay(pdMS_TO_TICKS(200));
      
      // 3. Live values
      snprintf(url_buf, sizeof(url_buf), "%s/api/v2/live", sat.base_url);
      if (fetch_to_buffer(url_buf, sat.live_json, sizeof(sat.live_json), &sat.live_len)) {
        sat.last_live_fetch = now;
        any_success = true;
      }
      
      // Update reachability
      if (any_success) {
        if (!sat.reachable) {
          ESP_LOGI(TAG, "Satellite %s: recovered (was unreachable)", sat.id);
        }
        sat.reachable = true;
        sat.consecutive_failures = 0;
        sat.last_seen_epoch = now;
      } else {
        sat.consecutive_failures++;
        if (sat.consecutive_failures >= 3 && sat.reachable) {
          sat.reachable = false;
          ESP_LOGW(TAG, "Satellite %s: marked unreachable (%d failures)", sat.id, sat.consecutive_failures);
        }
      }
      
      // Yield between satellites
      vTaskDelay(pdMS_TO_TICKS(500));
    }
    
    // Sleep until next poll cycle
    vTaskDelay(pdMS_TO_TICKS(5000));
  }
}

#endif // AGGREGATOR_ENABLED
```

### 6c. Start task conditionally in YAML

In `firmware/esp32-c3-multi-sensor.yaml`, in the `on_boot:` lambda:

```cpp
#if AGGREGATOR_ENABLED
  ESP_LOGI("aggregator", "Aggregator mode — starting poll task for %d satellite(s)", MAX_SATELLITES);
  xTaskCreate(aggregator_poll_task, "agg_poll", 8192, nullptr, tskIDLE_PRIORITY + 2, nullptr);
#endif
```

Stack size 8192 is needed for HTTP client buffers.

### 6d. Critical constraints

- **Sequential polling only** — never send concurrent requests to multiple satellites
- **Yield between every HTTP request** — `vTaskDelay(200ms)` minimum
- **Single-core awareness** — this task shares the core with BLE, WiFi, HTTP server, and PingAdapter
- **No dynamic allocation** — `SatelliteCache` array is static, sized by `MAX_SATELLITES`
- **Satellite firmware: ZERO changes** — the satellite doesn't know it's being polled
