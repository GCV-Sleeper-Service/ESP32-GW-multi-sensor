Prompt Deficiencies
The original prompt at prompts/phase5/v7.5.5.2-implementation-instructions-for-coding-agent.md had these issues:

Wrong proxy URL path: Section 4c step 1 says %s/history/%s/%s — should be %s/api/v2/history/%s/%s
No truncation detection: Rule 7 says "History proxy max response: 32KB" but doesn't say what to do when the upstream response exceeds 32KB. It should explicitly say "If s_proxy_len >= sizeof(s_proxy_tmp) - 1, return 502 with reason."
No mention of add_common_headers_() for proxy: The proxy response pattern is discussed separately from the gateways/live handlers but should mandate the same CORS headers.
