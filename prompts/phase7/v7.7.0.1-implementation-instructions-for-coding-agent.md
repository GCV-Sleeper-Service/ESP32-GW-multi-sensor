## 5. Exact Scope

Implement the per-device persist write path. This writes `DeviceSegment` blobs to NVS under device-specific keys. It runs **alongside** the old `persist_hourly_segment()` during the transition — both old and new blobs are written.

### 5a. Load and save DeviceHistoryMeta

```cpp
static bool load_device_meta_(nvs_handle_t handle, const char *device_id,
                               DeviceHistoryMeta *meta) {
  if (meta == nullptr || device_id == nullptr) return false;

  char key[12];
  make_device_meta_key_(device_id, key, sizeof(key));

  size_t sz = sizeof(DeviceHistoryMeta);
  esp_err_t err = nvs_get_blob(handle, key, meta, &sz);
  if (err != ESP_OK) {
    // No existing meta — this is OK for first persist
    return false;
  }

  // Validate magic and version
  if (meta->magic != DEV_HIST_MAGIC || meta->version != DEV_HIST_VERSION) {
    ESP_LOGW(TAG, "device meta %s: invalid magic/version — treating as new", key);
    return false;
  }

  // Validate device_id matches
  if (strncmp(meta->device_id, device_id, sizeof(meta->device_id)) != 0) {
    ESP_LOGW(TAG, "device meta %s: device_id mismatch (stored='%s' expected='%s') — hash collision?",
             key, meta->device_id, device_id);
    return false;
  }

  return true;
}

static bool save_device_meta_(nvs_handle_t handle, const DeviceHistoryMeta &meta) {
  char key[12];
  make_device_meta_key_(meta.device_id, key, sizeof(key));

  esp_err_t err = nvs_set_blob(handle, key, &meta, sizeof(meta));
  if (err != ESP_OK) {
    ESP_LOGE(TAG, "nvs_set_blob(%s) meta failed: %s", key, esp_err_to_name(err));
    return false;
  }
  err = nvs_commit(handle);
  if (err != ESP_OK) {
    ESP_LOGE(TAG, "nvs_commit meta %s failed: %s", key, esp_err_to_name(err));
    return false;
  }
  return true;
}
```

### 5b. Build DeviceSegment from one device's HistoryBuffers

```cpp
static bool build_device_segment_(int device_index, int metric_count,
                                   DeviceSegment *seg, uint32_t saved_at_epoch) {
  if (seg == nullptr || device_index < 0 || device_index >= NUM_DEVICES) return false;

  std::memset(seg, 0, sizeof(DeviceSegment));
  seg->header.magic = DEV_HIST_MAGIC;
  seg->header.version = DEV_HIST_VERSION;
  seg->header.metric_count = metric_count;
  seg->header.points_per_segment = PERSIST_POINTS_PER_SEGMENT;
  seg->header.saved_at_epoch = saved_at_epoch;

  bool any = false;
  uint32_t first_epoch = 0, last_epoch = 0;

  const SensorEntity &dev = devices[device_index];
  int actual_metrics = metric_count < MAX_PERSIST_METRICS ? metric_count : MAX_PERSIST_METRICS;

  for (int m = 0; m < actual_metrics; m++) {
    HistoryBuffer *buf = dev.metric_states[m].history;
    if (buf == nullptr) continue;

    seg->counts[m] = export_latest_entries_(*buf, seg->data[m], PERSIST_POINTS_PER_SEGMENT);

    if (seg->counts[m] > 0) {
      uint32_t local_first = seg->data[m][0].epoch;
      uint32_t local_last = seg->data[m][seg->counts[m] - 1].epoch;
      if (local_first > 0 && (first_epoch == 0 || local_first < first_epoch))
        first_epoch = local_first;
      if (local_last > last_epoch) last_epoch = local_last;
      any = true;
    }
  }

  seg->header.first_epoch = first_epoch;
  seg->header.last_epoch = last_epoch;
  return any && last_epoch > 0;
}
```

### 5c. Persist one device's segment

```cpp
static bool persist_device_segment_(int device_index, int metric_count,
                                     uint16_t max_slots) {
  if (max_slots == 0 || device_index < 0 || device_index >= NUM_DEVICES) return false;

  const char *dev_id = devices[device_index].id;

  // Build segment from RAM history
  DeviceSegment seg;
  uint32_t now = ::time(nullptr);
  if (!build_device_segment_(device_index, metric_count, &seg, now)) {
    ESP_LOGW(TAG, "persist_device %s: no data to persist", dev_id);
    return false;
  }

  // Open NVS read-write
  nvs_handle_t handle;
  if (!open_history_nvs_(&handle, NVS_READWRITE)) return false;

  // Load or initialize meta
  DeviceHistoryMeta meta;
  bool have_meta = load_device_meta_(handle, dev_id, &meta);
  if (!have_meta) {
    // First persist for this device — initialize meta
    std::memset(&meta, 0, sizeof(meta));
    meta.magic = DEV_HIST_MAGIC;
    meta.version = DEV_HIST_VERSION;
    meta.metric_count = metric_count;
    meta.points_per_segment = PERSIST_POINTS_PER_SEGMENT;
    meta.max_slots = max_slots;
    meta.valid_segments = 0;
    meta.next_slot = 0;
    meta.last_written_slot = 0xFFFF;
    meta.last_persist_epoch = 0;
    strncpy(meta.device_id, dev_id, sizeof(meta.device_id) - 1);
    meta.device_id[sizeof(meta.device_id) - 1] = '\0';
  }

  // Update max_slots from current budget (may have changed)
  meta.max_slots = max_slots;

  // Dedup: skip if already persisted this epoch
  if (meta.last_persist_epoch == seg.header.last_epoch) {
    ESP_LOGI(TAG, "persist_device %s: epoch %u already saved — skipping",
             dev_id, (unsigned)seg.header.last_epoch);
    nvs_close(handle);
    return true;
  }

  // Write segment blob
  char seg_key[16];
  int slot = meta.next_slot % max_slots;
  make_device_segment_key_(dev_id, slot, seg_key, sizeof(seg_key));

  esp_err_t err = nvs_set_blob(handle, seg_key, &seg, sizeof(seg));
  if (err != ESP_OK) {
    ESP_LOGE(TAG, "persist_device %s: nvs_set_blob(%s) failed: %s",
             dev_id, seg_key, esp_err_to_name(err));
    nvs_close(handle);
    return false;
  }

  // Update meta
  meta.last_written_slot = slot;
  meta.next_slot = (slot + 1) % max_slots;
  if (meta.valid_segments < max_slots) meta.valid_segments++;
  meta.last_persist_epoch = seg.header.last_epoch;
  meta.metric_count = metric_count;

  if (!save_device_meta_(handle, meta)) {
    nvs_close(handle);
    return false;
  }

  nvs_close(handle);
  ESP_LOGI(TAG, "persist_device %s: slot %03d (%u..%u), segments=%u",
           dev_id, slot,
           (unsigned)seg.header.first_epoch, (unsigned)seg.header.last_epoch,
           (unsigned)meta.valid_segments);
  return true;
}
```

### 5d. Persist all devices

```cpp
static void persist_all_devices_v2() {
  for (int i = 0; i < PERSIST_DEVICE_COUNT; i++) {
    int dev_idx = PERSIST_DEVICE_INDICES[i];
    int metric_count = PERSIST_METRIC_COUNTS[i];
    uint16_t max_slots = 460;  // TODO: replace with budget calculator in v7.7.0.2
    persist_device_segment_(dev_idx, metric_count, max_slots);
    maybe_yield_nvs_scan_(i);  // BUG-043: yield between devices
  }
}
```

## ADDENDUM: Post-Phase-5/6 Codebase Context (added 2026-03-22)

**Multi-board infrastructure exists.** Board profiles (`firmware/boards/*.yaml`), gateway config (`config/gateway.json`), and per-board partition tables are in the codebase. Phase 7 persistence changes are board-agnostic — `DeviceSegment` and `DeviceHistoryMeta` blobs are the same byte layout on all ESP32 variants. The partition SIZE differs (512KB on C3, 4MB on S3), which affects the retention budget calculation. The budget calculator already uses `esp_partition_find_first()` to read the actual partition size at runtime — no hardcoded sizes.

**Aggregator code exists in `sensor_history_multi.h`.** The `#if AGGREGATOR_ENABLED` block contains ~330 lines of aggregator infrastructure (SatelliteCache, polling task, API endpoints). Phase 7 persistence changes must NOT break the aggregator code. Specifically:
- The new `persist_device_segment_()` and `restore_device_()` functions operate on `devices[]` array entries. The aggregator doesn't persist satellite data locally — it caches JSON strings. No conflict.
- The new `/api/storage-stats` v2 response must work for both satellite (shows per-device persistence stats) and aggregator (shows local device persistence stats, if any local devices exist).
- If the aggregator has zero local persistent devices (`PERSIST_DEVICE_COUNT == 0`), the persist/restore loops execute zero iterations. Verify this.

**`esp_http_client.h` is NOT available.** Phase 7 is persistence-only (NVS reads/writes) — no HTTP client needed. But if any debugging/testing code needs HTTP, use `fetch_to_buffer()` with `lwip_*()` prefixed functions (LESSON-OPS-068).

**Zero-sensor configurations exist.** The generator can produce `NUM_DEVICES = 0`. Phase 7 code must handle:
- `PERSIST_DEVICE_COUNT = 0` — no devices to persist, budget calculator returns immediately
- Empty `PERSIST_DEVICE_IDS[]` array — restore loop iterates zero times
- `/api/storage-stats` returns a valid but empty `devices: {}` object
- Per-device delete API returns 404 for unknown device IDs (no devices = all IDs unknown)

**S3 partition gives 4MB history.** The retention budget calculation with a 4MB partition and 3 ThermoPro + 1 ping produces ~132 days per high-priority device vs ~19 days on C3's 512KB. The budget scenarios in the persistence architecture doc (Section 7.3) should be validated with the S3 partition size as well.
