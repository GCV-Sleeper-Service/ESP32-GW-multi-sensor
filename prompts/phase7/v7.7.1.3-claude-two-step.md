## External Reviewer Workflow

MEDIUM-RISK step. Send to Copilot + Codex inline, then one external. Focus areas:

1. **NVS write correctness:** Is the `DeviceSegment` blob written with correct key and size? Any alignment issues?
2. **Meta integrity:** Is `DeviceHistoryMeta` atomically consistent? What happens if power loss occurs between segment write and meta update?
3. **Ring buffer logic:** Does `next_slot % max_slots` wrap correctly? Any off-by-one in `valid_segments`?
4. **Dedup guard:** Is the half-window threshold correct for hourly persists?
5. **Memory safety:** No heap allocations — everything stack-local or global? `DeviceSegment` is 226 B on stack — safe?
6. **Yield compliance (Rule 61):** Is `maybe_yield_nvs_scan_()` called correctly between device persists?

   **Why this matters:** Omitting the `vTaskDelay(pdMS_TO_TICKS(5))` yield in NVS scan loops causes watchdog resets under multi-device iteration on ESP32-C3 (single-core RISC-V) (BUG-043 rev2 — 1ms proved insufficient; verified against `firmware/core/nvs-persistence.h:248`). See LESSON-OPS-127 / BUG-043 in `Docs/lessons/firmware.md`.
