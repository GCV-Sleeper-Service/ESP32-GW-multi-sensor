## External Reviewer Workflow

This is a HIGH-RISK step. Send to ALL reviewers with these focus areas:

1. **Memory safety:** Is the SegmentSnapshot correctly allocated and freed on all code paths (including error paths)?
2. **httpd API correctness:** Does `httpd_resp_send_chunk()` work correctly when called from within the AsyncWebHandler framework via the `httpd_req_t*` conversion operator? Any re-entrancy concerns?
3. **Buffer overflow:** Do the `snprintf` calls in the helpers correctly guard against buffer overrun?
4. **Connection abort handling:** What happens if the client disconnects mid-stream? Does `httpd_resp_send_chunk` return an error that stops the loop?
5. **CSV format preservation:** Is the output byte-identical to the old implementation for the same input data?
