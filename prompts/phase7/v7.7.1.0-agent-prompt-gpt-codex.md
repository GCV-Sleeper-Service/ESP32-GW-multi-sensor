## §5 — DO-NOT List

- Do NOT perform any NVS write operations in the health-check task. It is read-only telemetry.
- Do NOT use `beginResponseStream` or create any HTTP endpoints in health-check.h. It only logs via `ESP_LOGI`.
- Do NOT use `esp_get_free_heap_size()` alone — it includes PSRAM on S3/C5 boards. Use `esp_get_free_internal_heap_size()` for internal heap AND `esp_get_free_heap_size()` for total.

- Do NOT add the health-check task to the deferred-management.h fragment. It is a standalone fragment.

- Do NOT reorder existing fragments in `assemble-sensor-history.sh` (Rule 62). Only INSERT the new entry.

## §6 — Implementation Instructions

### Task Group 1: Create `firmware/core/health-check.h`

Create the file `firmware/core/health-check.h` with this content:

```cpp
// ═══════════════════════════════════════════════════════════════════
// health-check.h — Periodic telemetry task (Phase 7 Step v7.7.1.0)
// Source fragment: firmware/core/health-check.h
// Assembled output: dashboard/sensor_history_multi.h
//
// Implements BUG-075/076 postmortem recommendation: periodic health
// logging of heap, stack watermarks, NVS stats, and uptime.
// Read-only telemetry — no NVS writes, no HTTP endpoints.
// ═══════════════════════════════════════════════════════════════════

#ifndef HEALTH_CHECK_INTERVAL_S
#define HEALTH_CHECK_INTERVAL_S 60
#endif

static void health_check_task_(void *param) {
  // Wait 30s after boot before first report — let system stabilize
  vTaskDelay(pdMS_TO_TICKS(30000));

  for (;;) {
    // ── Heap stats ────────────────────────────────────────────────
    uint32_t free_internal = esp_get_free_internal_heap_size();
    uint32_t free_total    = esp_get_free_heap_size();
    uint32_t min_free_internal =
        heap_caps_get_minimum_free_size(MALLOC_CAP_INTERNAL);
    uint32_t min_free_total = esp_get_minimum_free_heap_size();

    // ── Stack watermarks ─────────────────────────────────────────
    // Health-check task's own stack watermark
    UBaseType_t hc_stack_wm = uxTaskGetStackHighWaterMark(nullptr);

    // httpd task watermark — search by name "httpd"
    TaskHandle_t httpd_task = xTaskGetHandle("httpd");
    UBaseType_t httpd_stack_wm = 0;
    if (httpd_task != nullptr) {
      httpd_stack_wm = uxTaskGetStackHighWaterMark(httpd_task);
    }

    // ── NVS partition stats ──────────────────────────────────────
    nvs_stats_t nvs_stats{};
    esp_err_t nvs_err = nvs_get_stats(HISTORY_PARTITION_LABEL, &nvs_stats);

    // ── Uptime ───────────────────────────────────────────────────
    uint32_t uptime_s = (uint32_t)(esp_timer_get_time() / 1000000ULL);
    uint32_t uptime_h = uptime_s / 3600;
    uint32_t uptime_m = (uptime_s % 3600) / 60;

    // ── Log everything ───────────────────────────────────────────
    ESP_LOGI(TAG, "HEALTH: heap_free=%u heap_free_total=%u "
             "min_free=%u min_free_total=%u "
             "uptime=%uh%02um",
             (unsigned)free_internal, (unsigned)free_total,
             (unsigned)min_free_internal, (unsigned)min_free_total,
             (unsigned)uptime_h, (unsigned)uptime_m);

    ESP_LOGI(TAG, "HEALTH: httpd_stack_wm=%u hc_stack_wm=%u",
             (unsigned)(httpd_stack_wm * sizeof(StackType_t)),
             (unsigned)(hc_stack_wm * sizeof(StackType_t)));

    if (nvs_err == ESP_OK) {
      ESP_LOGI(TAG, "HEALTH: nvs_used=%u nvs_free=%u nvs_total=%u "
               "nvs_ns_count=%u",
               (unsigned)nvs_stats.used_entries,
               (unsigned)nvs_stats.free_entries,
               (unsigned)nvs_stats.total_entries,
               (unsigned)nvs_stats.namespace_count);
    } else {
      ESP_LOGW(TAG, "HEALTH: nvs_get_stats failed: %s",
               esp_err_to_name(nvs_err));
    }

    vTaskDelay(pdMS_TO_TICKS(HEALTH_CHECK_INTERVAL_S * 1000));
  }
  // Task never exits
}

static void start_health_check_task_() {
  BaseType_t ret = xTaskCreate(
      health_check_task_,
      "health_chk",         // Task name (max 16 chars)
      4096,                 // Stack size in bytes
      nullptr,              // No parameters
      1,                    // Priority 1 (background)
      nullptr               // No handle needed
  );
  if (ret != pdPASS) {
    ESP_LOGE(TAG, "start_health_check_task_: xTaskCreate failed (ret=%d)",
             (int)ret);
  } else {
    ESP_LOGI(TAG, "Health-check task started (interval=%ds, stack=4096B)",
             HEALTH_CHECK_INTERVAL_S);
  }
}
```

**Important implementation notes on the code above:**

1. `uxTaskGetStackHighWaterMark` returns words, not bytes. Multiply by `sizeof(StackType_t)` for bytes (as done in the existing `ping-adapter.h` at line ~152).
2. `xTaskGetHandle("httpd")` searches all tasks by name — the httpd task name is "httpd" in ESP-IDF's `esp_http_server`. If the name differs in this ESPHome version, the function returns nullptr and we skip reporting it (safe degradation).
3. `nvs_get_stats()` takes a partition label string, not an open handle. No NVS open/close needed.
4. `MALLOC_CAP_INTERNAL` excludes PSRAM — this is the metric that matters for non-PSRAM boards.
5. The 30-second initial delay prevents health-check logs from interleaving with boot messages.
