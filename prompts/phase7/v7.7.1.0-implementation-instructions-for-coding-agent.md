## 5. Exact Scope

### 5a. Migration detection

Add `check_and_run_migration_()` called early in the boot sequence, before `restore_all_devices_v2()`:

```cpp
static constexpr const char *V7_MIGRATED_KEY = "v7_migrated";

static bool is_v7_migrated_() {
  nvs_handle_t handle;
  if (!open_history_nvs_(&handle, NVS_READONLY)) return false;

  uint8_t flag = 0;
  esp_err_t err = nvs_get_u8(handle, V7_MIGRATED_KEY, &flag);
  nvs_close(handle);
  return (err == ESP_OK && flag == 1);
}

static bool has_v7_history_() {
  nvs_handle_t handle;
  if (!open_history_nvs_(&handle, NVS_READONLY)) return false;

  HistoryMeta meta;
  size_t sz = sizeof(HistoryMeta);
  esp_err_t err = nvs_get_blob(handle, "hist_meta", &meta, &sz);
  nvs_close(handle);

  if (err != ESP_OK) return false;
  return meta.magic == HISTORY_META_MAGIC &&
         meta.version == HISTORY_META_VERSION &&
         meta.valid_segments > 0;
}
```

### 5b. Migration algorithm

```cpp
static constexpr int MIGRATION_MAX_SEGMENTS = 24;  // migrate most recent 24 hours

static bool migrate_v7_to_v8_() {
  ESP_LOGI(TAG, "v7→v8 migration: starting");

  // 1. Read old meta
  nvs_handle_t rh;
  if (!open_history_nvs_(&rh, NVS_READONLY)) return false;

  HistoryMeta old_meta;
  if (!load_history_meta_(rh, &old_meta)) {
    ESP_LOGW(TAG, "v7→v8 migration: old meta unreadable — nothing to migrate");
    nvs_close(rh);
    return true;  // not an error, just nothing to migrate
  }

  if (old_meta.valid_segments == 0) {
    ESP_LOGI(TAG, "v7→v8 migration: old meta has 0 segments — nothing to migrate");
    nvs_close(rh);
    return true;
  }

  // 2. Calculate which old segments to read (newest MIGRATION_MAX_SEGMENTS)
  int migrate_count = old_meta.valid_segments < MIGRATION_MAX_SEGMENTS
                          ? old_meta.valid_segments
                          : MIGRATION_MAX_SEGMENTS;
  int oldest_valid = (old_meta.next_slot + PERSIST_SLOTS - old_meta.valid_segments) % PERSIST_SLOTS;
  int start_offset = old_meta.valid_segments > migrate_count
                         ? (old_meta.valid_segments - migrate_count)
                         : 0;
  int first_slot = (oldest_valid + start_offset) % PERSIST_SLOTS;

  ESP_LOGI(TAG, "v7→v8 migration: migrating %d of %d segments (newest)",
           migrate_count, (int)old_meta.valid_segments);

  // 3. Allocate old-format snapshot buffer (stack is OK — 230 bytes)
  SegmentSnapshot old_snap;

  // 4. Read old segments and convert to per-device format
  nvs_close(rh);  // close read-only — will reopen read-write for writing

  nvs_handle_t wh;
  if (!open_history_nvs_(&wh, NVS_READWRITE)) return false;

  // Initialize per-device meta for each environmental device
  DeviceHistoryMeta dev_metas[NUM_ENV_SENSORS];
  for (int i = 0; i < NUM_ENV_SENSORS; i++) {
    std::memset(&dev_metas[i], 0, sizeof(DeviceHistoryMeta));
    dev_metas[i].magic = DEV_HIST_MAGIC;
    dev_metas[i].version = DEV_HIST_VERSION;
    dev_metas[i].metric_count = 2;  // temp + hum
    dev_metas[i].points_per_segment = PERSIST_POINTS_PER_SEGMENT;
    dev_metas[i].max_slots = MIGRATION_MAX_SEGMENTS;  // will be recalculated at next boot
    dev_metas[i].valid_segments = 0;
    dev_metas[i].next_slot = 0;
    dev_metas[i].last_written_slot = 0xFFFF;
    dev_metas[i].last_persist_epoch = 0;
    strncpy(dev_metas[i].device_id, devices[i].id, sizeof(dev_metas[i].device_id) - 1);
  }

  int migrated = 0;
  for (int n = 0; n < migrate_count; n++) {
    maybe_yield_nvs_scan_(n);  // BUG-043: yield every 4

    int old_slot = (first_slot + n) % PERSIST_SLOTS;

    // Read old snapshot (re-open read for each? No — we have read-write handle, can read too)
    char old_key[12];
    make_segment_key_(old_slot, old_key, sizeof(old_key));

    size_t sz = sizeof(SegmentSnapshot);
    esp_err_t err = nvs_get_blob(wh, old_key, &old_snap, &sz);
    if (err != ESP_OK) {
      // BUG-048: old blob may be incompatible size — skip it
      if (err == ESP_ERR_NVS_INVALID_LENGTH) {
        ESP_LOGW(TAG, "v7→v8 migration: %s size mismatch (stored=%u expected=%u) — skipping",
                 old_key, (unsigned)sz, (unsigned)sizeof(SegmentSnapshot));
      }
      continue;
    }

    // Validate old snapshot
    if (old_snap.header.magic != HISTORY_META_MAGIC ||
        old_snap.header.num_sensors != NUM_SENSORS) {
      ESP_LOGW(TAG, "v7→v8 migration: %s schema mismatch — skipping", old_key);
      continue;
    }

    // Convert to per-device DeviceSegments
    for (int i = 0; i < NUM_ENV_SENSORS; i++) {
      DeviceSegment new_seg;
      std::memset(&new_seg, 0, sizeof(new_seg));
      new_seg.header.magic = DEV_HIST_MAGIC;
      new_seg.header.version = DEV_HIST_VERSION;
      new_seg.header.metric_count = 2;
      new_seg.header.points_per_segment = PERSIST_POINTS_PER_SEGMENT;
      new_seg.header.saved_at_epoch = old_snap.header.saved_at_epoch;

      // Metric 0 = temp
      new_seg.counts[0] = old_snap.temp_counts[i];
      for (int p = 0; p < old_snap.temp_counts[i] && p < PERSIST_POINTS_PER_SEGMENT; p++) {
        new_seg.data[0][p] = old_snap.temp[i][p];
      }

      // Metric 1 = hum
      new_seg.counts[1] = old_snap.hum_counts[i];
      for (int p = 0; p < old_snap.hum_counts[i] && p < PERSIST_POINTS_PER_SEGMENT; p++) {
        new_seg.data[1][p] = old_snap.hum[i][p];
      }

      // Calculate epochs
      uint32_t first_ep = 0, last_ep = 0;
      for (int m = 0; m < 2; m++) {
        for (int p = 0; p < new_seg.counts[m]; p++) {
          uint32_t ep = new_seg.data[m][p].epoch;
          if (ep > 0) {
            if (first_ep == 0 || ep < first_ep) first_ep = ep;
            if (ep > last_ep) last_ep = ep;
          }
        }
      }
      new_seg.header.first_epoch = first_ep;
      new_seg.header.last_epoch = last_ep;

      // Write new segment
      int new_slot = dev_metas[i].next_slot;
      char new_key[16];
      make_device_segment_key_(devices[i].id, new_slot, new_key, sizeof(new_key));

      err = nvs_set_blob(wh, new_key, &new_seg, sizeof(new_seg));
      if (err != ESP_OK) {
        ESP_LOGE(TAG, "v7→v8 migration: write %s failed: %s", new_key, esp_err_to_name(err));
        continue;
      }

      dev_metas[i].next_slot = (new_slot + 1) % dev_metas[i].max_slots;
      dev_metas[i].valid_segments++;
      dev_metas[i].last_written_slot = new_slot;
      dev_metas[i].last_persist_epoch = last_ep;
    }

    migrated++;
  }

  // 5. Save per-device metas
  for (int i = 0; i < NUM_ENV_SENSORS; i++) {
    if (dev_metas[i].valid_segments > 0) {
      save_device_meta_(wh, dev_metas[i]);
      ESP_LOGI(TAG, "v7→v8 migration: %s — %u segments migrated",
               devices[i].id, (unsigned)dev_metas[i].valid_segments);
    }
  }

  // 6. Set v7_migrated flag
  nvs_set_u8(wh, V7_MIGRATED_KEY, 1);
  nvs_commit(wh);
  nvs_close(wh);

  ESP_LOGI(TAG, "v7→v8 migration: complete — %d of %d old segments converted", migrated, migrate_count);
  return true;
}
```

### 5c. Wire into boot flow

In the boot sequence (before `restore_all_devices_v2()`):

```cpp
static void check_and_run_migration_() {
  if (is_v7_migrated_()) {
    ESP_LOGI(TAG, "v7→v8 migration: already completed — skipping");
    return;
  }
  if (!has_v7_history_()) {
    ESP_LOGI(TAG, "v7→v8 migration: no v7 history found — fresh install");
    // Set flag so we don't check again
    nvs_handle_t h;
    if (open_history_nvs_(&h, NVS_READWRITE)) {
      nvs_set_u8(h, V7_MIGRATED_KEY, 1);
      nvs_commit(h);
      nvs_close(h);
    }
    return;
  }
  migrate_v7_to_v8_();
}
```

**IMPORTANT:** The old `restore_from_nvs()` call should be REMOVED from the boot flow at this point (it was already replaced by `restore_all_devices_v2()` in v7.7.0.3). The migration writes v8 blobs, and `restore_all_devices_v2()` reads them.

## 7. Critical Rules

1. `v7_migrated` flag is an `nvs_set_u8`/`nvs_get_u8` — NOT a blob
2. Migration is idempotent — running twice must not corrupt data
3. Old blobs with `ESP_ERR_NVS_INVALID_LENGTH` (BUG-048) are skipped gracefully
4. `maybe_yield_nvs_scan_()` every 4 segments during migration
5. All NVS handles closed on every error path
6. `nvs_commit()` after all writes before closing handle
7. `DEV_HIST_MAGIC != HISTORY_META_MAGIC` — this is how we distinguish old from new blobs
8. Run Playwright — CI-exact commands from §4 Pre-condition Checks (all fixture sets, both browsers)
9. Prompt-provided code blocks in this file have been reviewed as production code (Rule 29) — copy faithfully but report any issues found
10. All fixture sets (3sensor, mixed, aggregator, system) must pass (Rules 30–32)

## ADDENDUM: Post-Phase-5/6 Codebase Context (added 2026-03-22)

**Multi-board infrastructure exists.** Board profiles (`firmware/boards/*.yaml`), gateway config (`config/gateway.json`), and per-board partition tables are in the codebase. Phase 7 persistence changes are board-agnostic — `DeviceSegment` and `DeviceHistoryMeta` blobs are the same byte layout on all ESP32 variants. The partition SIZE differs (512KB on C3, 4MB on S3), which affects the retention budget calculation. The budget calculator already uses `esp_partition_find_first()` to read the actual partition size at runtime — no hardcoded sizes.

**Aggregator code exists in `sensor_history_multi.h`.** The `#if AGGREGATOR_ENABLED` block contains ~330 lines of aggregator infrastructure (SatelliteCache, polling task, API endpoints). Phase 7 persistence changes must NOT break the aggregator code. Specifically:
- The new `persist_device_segment_()` and `restore_device_()` functions operate on `devices[]` array entries. The aggregator doesn't persist satellite data locally — it caches JSON strings. No conflict.
- The new `/api/storage-stats` v2 response must work for both satellite (shows per-device persistence stats) and aggregator (shows local device persistence stats, if any local devices exist).
- If the aggregator has zero local persistent devices (`PERSIST_DEVICE_COUNT == 0`), the persist/restore loops execute zero iterations. Verify this.

**`esp_http_client.h` is NOT available.** Phase 7 is persistence-only (NVS reads/writes) — no HTTP client needed. But if any debugging/testing code needs HTTP, use `fetch_to_buffer()` with `lwip_*()` prefixed functions (LESSON-OPS-068).

**Zero-sensor configurations exist.** The generator can produce `NUM_DEVICES = 0`. Phase 7 code must handle:
- `PERSIST_DEVICE_COUNT = 0` — no devices to persist, budget calculator returns immediately
- Empty `PERSIST_DEVICE_IDS[]` array — restore loop iterates zero times
- `/api/storage-stats` returns a valid but empty `devices: {}` object
- Per-device delete API returns 404 for unknown device IDs (no devices = all IDs unknown)

**S3 partition gives 4MB history.** The retention budget calculation with a 4MB partition and 3 ThermoPro + 1 ping produces ~132 days per high-priority device vs ~19 days on C3's 512KB. The budget scenarios in the persistence architecture doc (Section 7.3) should be validated with the S3 partition size as well.
