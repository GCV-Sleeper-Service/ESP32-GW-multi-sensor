## Architecture Decisions Validated

- D1: Option B (assembled artifact) — zero YAML changes, zero generator changes
- D2: `firmware/core/` as fragment directory — clean firmware code location
- D3: Generator unchanged — writes into assembled file only, not fragments
- D4: SHA-256 identity gate — deterministic, portable verification, strips generator regions
- D5: Single web-handler.h (2,006 lines) — preserves class syntactic completeness
- D6: Aggregator two-island resolved by assembly order — re-joined before compiler sees code
- D8: YAML `includes:` unchanged — compiler sees only assembled artifact
