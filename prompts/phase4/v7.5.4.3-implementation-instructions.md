## Exact scope

Create mixed-category test fixtures and add Playwright tests to validate that the dashboard correctly renders both environmental and network device categories simultaneously.

### Step-by-step:

1. **Create `tests/fixtures/variants/mixed/` directory** with fixtures for a mixed-category deployment:
   - `sensors.json` — v1 projection: 2 ThermoPro sensors only (legacy compat)
   - `manifest.json` — v2 manifest: 2 ThermoPro + 1 wan_ping device
   - `api-status.json` — gateway status
   - `storage-stats.json` — storage stats
   - `history-office-temp.csv`, `history-office-hum.csv` — ThermoPro history
   - `history-first_floor-temp.csv`, `history-first_floor-hum.csv` — ThermoPro history
   - `history-wan_ping-ping_ms.csv` — ping latency history (10-20 data points)
   - `history-wan_ping-success_pct.csv` — ping success history

2. **Extend `tests/fixtures/generate-fixtures.js`** to generate the mixed variant from a mixed-category manifest.

3. **Extend `tests/mock-server/server.js`** if needed:
   - Ensure `/api/v2/live` builds response correctly for mixed categories
   - Ensure history endpoints serve ping metric fixtures
   - Verify that `FIXTURE_SET=mixed` loads the variant fixtures correctly

4. **Add Playwright test Group 17: Mixed-Category Rendering** to `tests/browser/dashboard.spec.js`:

   ```
   Test 1: Mixed manifest renders correct number of cards (2 environmental + 1 network)
   Test 2: Environmental cards render with expected ThermoPro layout
   Test 3: Network card renders with latency and success rate
   Test 4: CARD_RENDERERS dispatches correctly by category
   Test 5: Chart rendering works for environmental devices
   Test 6: /api/v2/live returns data for both device categories
   Test 7: Manifest v2 contains both environmental and network devices
   ```

   Run these tests with `FIXTURE_SET=mixed` environment variable.

5. **Update changelog, session log, bump to 7.5.4.3**

### Test execution:

The mixed-category tests should use the `FIXTURE_SET=mixed` environment variable:

```bash
# Run only the mixed-category tests:
FIXTURE_SET=mixed npx playwright test --project=chromium --grep "Mixed-Category"

# Run the full suite (root baseline):
npx playwright test --project=chromium

# Both must pass.
```
