## Exact scope

Implement ICMP ping adapter as periodic RTOS task.

1. Add `PingAdapter` class to `sensor_history_multi.h` (or new `src/ping_adapter.h`)
2. RTOS task pings configured target every 60 seconds (3 pings per cycle, 200ms spacing)
3. Calls `devices[n].add_sample(0, avg_rtt)` and `devices[n].add_sample(1, success_pct)`
4. Handle DNS resolution, network-down gracefully (mark metrics invalid, don't crash)
5. Add adapter initialization in YAML setup lambda (generator-driven)
6. Update changelog, session log, bump to 7.5.4.1

**Critical:** Single-core ESP32-C3 — keep ping task execution brief (~600ms per cycle). Handle errors gracefully.
