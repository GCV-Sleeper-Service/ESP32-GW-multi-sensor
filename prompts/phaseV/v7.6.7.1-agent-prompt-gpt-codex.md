## §5 — Implementation Instructions

### Task Group 1: Add Import State Variables

**Step 1.1 — Add `s_import_ready` flag**

In `firmware/core/web-handler.h`, find the existing `s_import_*` state variables (near line ~770–778). Add:

```cpp
static volatile bool s_import_ready = false;
```

Place it adjacent to other `s_import_*` variables. The `volatile` qualifier is mandatory because this flag is written by a FreeRTOS task and read by the httpd task.

### Task Group 2: Create Deferred Import Task

**Step 2.1 — Add the task function**

Add the following BEFORE `handle_import_begin_()` (around line ~775):

```cpp
static void import_epoch_map_task_(void *arg) {
  auto *handler = static_cast<HistoryWebHandler*>(arg);
  // Run the heavy NVS scan in this task's stack (8192 B), not on httpd (4 KB)
  handler->build_import_epoch_map_();
  s_import_ready = true;
  ESP_LOGI(TAG, "Import epoch map ready");
  vTaskDelete(nullptr);
}
```

Note: `build_import_epoch_map_()` may need to be made non-`const` or the handler pointer adjusted. Check the existing signature at line ~697. If it's a `const` method, you may need `const_cast` — but prefer making the method non-const if feasible.

### Task Group 3: Modify `handle_import_begin_()`

**Step 3.1 — Replace the synchronous call**

Read `handle_import_begin_()` at line ~779. Find the block (around line ~791):

```cpp
if (!build_import_epoch_map_()) {
  // error handling
}
```

Replace with:

```cpp
s_import_ready = false;
BaseType_t created = xTaskCreate(import_epoch_map_task_, "imp_epoch",
                                 8192, (void*)this, 5, nullptr);
if (created != pdPASS) {
  cleanup_import_state_();
  std::string err = "{\"ok\":false,\"message\":\"Failed to create import task\"}";
  auto *resp = request->beginResponse(500, "application/json", err.c_str());
  add_common_headers_(resp);
  request->send(resp);
  return;
}

// Respond immediately — task runs in background
std::string body = "{\"ok\":true,\"status\":\"queued\"}";
auto *resp = request->beginResponse(200, "application/json", body.c_str());
add_common_headers_(resp);
request->send(resp);
return;
```

**Step 3.2 — Fix the `beginResponseStream` at line ~817**

Find the `beginResponseStream` call at line ~817 (the response for the non-single-sensor import path). Replace:

```cpp
auto *resp = request->beginResponseStream("application/json");
```

with a pre-built string + `beginResponse()`:

```cpp
std::string body = "{\"ok\":true,\"status\":\"queued\"}";
auto *resp = request->beginResponse(200, "application/json", body.c_str());
```

Ensure the response is sent before any NVS work begins. Apply the same deferred task pattern to the multi-sensor import path if it also calls `build_import_epoch_map_()` synchronously.
