### Decision Logic

- If total gain < 300 B: document as v8 data model consideration in issue #165, close with no code change.
- If total gain ≥ 300 B: implement struct changes.

1. Read `firmware/core/nvs-persistence.h` — check if NVS code uses `sizeof(SensorEntity)`, `offsetof()`, or iterates member pointers

3. **If serialisation depends on struct layout (sizeof or offset):** DO NOT CHANGE the struct — document the constraint as a Phase 7/v8 consideration and close with no code change
