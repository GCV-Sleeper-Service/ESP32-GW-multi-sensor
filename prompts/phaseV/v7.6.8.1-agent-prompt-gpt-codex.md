## §5 — Implementation Instructions

### Task Group 1: V2-E — History Auth + Heap Cap

**Step 1.1 — Add auth to `/history/` handler**

Find `handle_history_()` in `firmware/core/web-handler.h`. Add as first line:

```cpp
// Auth: REQUIRED — large-allocation endpoint, prevents anonymous heap exhaustion (SEC-05)
if (!authenticate_management_(request)) return;
```

**Step 1.2 — Add auth to `/api/v2/history/` handler**

Find `handle_api_v2_history_()`. Add same auth guard:

```cpp
// Auth: REQUIRED — large-allocation endpoint (SEC-05)
if (!authenticate_management_(request)) return;
```

**Step 1.3 — Cap `csv.reserve()`**

Find every `csv.reserve()` call in the history handlers. Replace:

```cpp
csv.reserve(est_bytes);
```

with:

```cpp
csv.reserve(std::min(est_bytes, (size_t)60000));
```

This caps allocation at 60 KB — fits within C3's safe heap margin with ~5 KB remaining.

### Task Group 2: V2-F — DoS Cooldown on add-satellite

**Step 2.1 — Add cooldown state**

In the appropriate fragment (either `web-handler.h` near `handle_add_satellite_()` or `aggregator-runtime.h` near `probe_satellite_manifest_()`), add:

```cpp
static constexpr int MAX_PROBE_COOLDOWN = 8;  // or MAX_SATELLITES
static uint32_t s_last_probe_fail_epoch[MAX_PROBE_COOLDOWN] = {};
static char s_last_probe_fail_url[MAX_PROBE_COOLDOWN][128] = {};
```

**Step 2.2 — Check cooldown before probe**

Before calling `probe_satellite_manifest_()` in `handle_add_satellite_()`, add:

```cpp
uint32_t now = (uint32_t)::time(nullptr);
for (int i = 0; i < MAX_PROBE_COOLDOWN; i++) {
  if (s_last_probe_fail_url[i][0] != '\0' &&
      strcmp(s_last_probe_fail_url[i], url) == 0 &&
      now - s_last_probe_fail_epoch[i] < 60) {
    std::string err = "{\"ok\":false,\"message\":\"Too many requests for this URL — retry after 60s\"}";
    auto *resp = request->beginResponse(429, "application/json", err.c_str());
    add_common_headers_(resp);
    request->send(resp);
    return;
  }
}
```

**Step 2.3 — Record failures**

After a failed probe, store the URL and current time in the cooldown array (find a free slot or overwrite the oldest).
