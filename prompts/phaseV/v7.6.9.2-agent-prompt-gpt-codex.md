### Task Group 1: V3-D — Replace EXPORT_SENSOR_SUFFIXES with Manifest-Driven Function

**Step 1.1 — Add `getMetricColumnsForSensor()` to `dashboard/core/sensor-defs.js`**

Find `EXPORT_SENSOR_SUFFIXES` at line ~13:
```javascript
var EXPORT_SENSOR_SUFFIXES = ['temp_c', 'temp_f', 'humidity_pct', 'dewpoint_c'];
```

Replace with:
```javascript
// Manifest-driven metric columns — replaces static EXPORT_SENSOR_SUFFIXES
function getMetricColumnsForSensor(sensor, manifest) {
  if (!manifest) return ['temp', 'hum']; // fallback for backward compat when manifest unavailable
  var sensors = manifest.sensors || [];
  var sensorDef = null;
  for (var i = 0; i < sensors.length; i++) {
    if (sensors[i].id === sensor.id) { sensorDef = sensors[i]; break; }
  }
  if (!sensorDef || !sensorDef.measurements) return [];
  var cols = [];
  for (var j = 0; j < sensorDef.measurements.length; j++) {
    if (sensorDef.measurements[j].history === true) {
      cols.push(sensorDef.measurements[j].key);
    }
  }
  return cols;
}
```

**Step 1.2 — Update all `EXPORT_SENSOR_SUFFIXES` usages**
