```cpp

```

Replace with:
```cpp

```

Inside the function body, find the `lwip_setsockopt()` call for `SO_RCVTIMEO` (and `SO_SNDTIMEO` if present). Replace the hardcoded timeout value with `timeout_s`:

```cpp

tv.tv_sec = timeout_s;
tv.tv_usec = 0;

lwip_setsockopt(sock, SOL_SOCKET, SO_SNDTIMEO, &tv, sizeof(tv));
```

After parsing the HTTP response status line (e.g., `HTTP/1.1 200 OK`), store the status code if `out_http_status` is non-null:


**Step 1.3 — Modify `handle_aggregator_proxy_()` in `firmware/core/web-handler.h`**

Read `firmware/core/web-handler.h` lines 1556–1610 (the full `handle_aggregator_proxy_()` function).

Find the `fetch_to_buffer()` call inside this function (currently around line 1580–1590). Replace the existing fetch and response logic with:

```cpp

                     static_cast<uint16_t>(sizeof(s_proxy_tmp)),
                     &s_proxy_len,
                     15,                  // proxy passes 15s timeout (satellite history can be slow)
                     &satellite_http_status)) {
  // Satellite unreachable or returned error — log and return 502 with JSON diagnostic

           "{\"error\":\"upstream_fetch_failed\",\"url\":\"%s\",\"http_status\":%d}",
           url, satellite_http_status);

  add_common_headers_(resp);
  request->send(resp);
  return;
}

// Satellite returned 200 but has no history — return 200 with empty body (NOT 502)
if (s_proxy_len == 0) {
  auto *resp = request->beginResponse(200, "text/plain", "");
  add_common_headers_(resp);
  request->send(resp);
  return;
}
```
