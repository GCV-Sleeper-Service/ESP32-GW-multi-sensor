## §5 — Implementation Instructions

### Task Group 1: V3-B — Satellite Hostname and IP in Gateways Response

**Step 1.1 — Firmware: extract hostname from manifest JSON**

In `firmware/core/web-handler.h`, in `handle_aggregator_gateways_()` (starts at line ~1431), find the loop that iterates `satellite_caches[]` and builds JSON for each satellite.

For each satellite, after the existing JSON fields are emitted:

1. Extract `hostname` from `sat.manifest_json` — search within the `"gateway":{` object ONLY (avoid false matches in sensor names). Use simple `strstr()` or manual parsing — do NOT use a JSON library.
2. Extract `ip` from `sat.base_url` — strip `http://` prefix, take the host portion before any `:` (port) or `/` (path).
3. Emit `,\"hostname\":\"...\"` and `,\"ip\":\"...\"` in the JSON for each satellite.

Example extraction for hostname:
```cpp
// Find "gateway":{...} in manifest, then "name":"..." within it
const char* gw_obj = strstr(satellite_caches[i].manifest_json, "\"gateway\":{");
char hostname[64] = "";
if (gw_obj) {
  const char* name_key = strstr(gw_obj, "\"name\":\"");
  if (name_key) {
    name_key += 8;  // skip past "name":"
    const char* end = strchr(name_key, '"');
    if (end && (end - name_key) < (int)sizeof(hostname)) {
      memcpy(hostname, name_key, end - name_key);
      hostname[end - name_key] = '\0';
    }
  }
}
```

Example extraction for IP from base_url:
```cpp
char ip[48] = "";
const char* url = satellite_caches[i].base_url;
if (strncmp(url, "http://", 7) == 0) {
  const char* host_start = url + 7;
  const char* host_end = strpbrk(host_start, ":/");
  size_t len = host_end ? (size_t)(host_end - host_start) : strlen(host_start);
  if (len < sizeof(ip)) { memcpy(ip, host_start, len); ip[len] = '\0'; }
}
```

After edits: `bash scripts/assemble-sensor-history.sh --write`

**Step 1.2 — Dashboard: display hostname and IP in gateway panel**

In `dashboard/components/gateway-panel/index.js`:

- `renderAllGatewaysSummary()` (line ~49): use `gw.hostname || gw.name` as the display name for each gateway summary card. Add an IP address row before the Last Seen row.
- `renderGatewaySelector()` (line ~16): use `gw.hostname || gw.name` as the tab label text.
- `renderSettingsPanel()` (line ~234): add hostname and IP as info rows in the satellite settings cards.

**Step 2.2 — Add `getExportRole()` function**

In `dashboard/core/sensor-defs.js`, after the `EXPORT_SHARED_COLUMNS` definition, add:

function getExportRole(sensor, manifest) {
