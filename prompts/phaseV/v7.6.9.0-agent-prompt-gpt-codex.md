### Task Group 2: Issue #136 — Hardcoded C3 Values

**Step 2.1 — Add ESPHome text_sensor entities to YAML**

In `firmware/esp32-c3-multi-sensor.yaml`, add template text_sensors for Flash and SRAM. Use ESPHome's platform APIs:

```yaml
text_sensor:
  - platform: template
    name: "Flash Size"
    id: flash_size
    lambda: |-
      char buf[32];
      snprintf(buf, sizeof(buf), "%u KB", spi_flash_get_chip_size() / 1024);
      return std::string(buf);
    update_interval: never

  - platform: template
    name: "SRAM Size"
    id: sram_size
    lambda: |-
      return std::string("400 KB");  // C3 SuperMini has 400 KB SRAM
    update_interval: never
```

Note: `spi_flash_get_chip_size()` is an ESP-IDF API available in ESPHome. For SRAM, use the known value for the board — ESPHome doesn't expose a runtime SRAM total API.

**Step 2.2 — Add IDs to template and DEVICE_INFO_MAP**

In `dashboard/components/device-info/template.html`, add rows:
```html
<div class="device-info-row"><span class="device-info-label">Flash:</span><span class="device-info-value loading" id="di-flash">loading...</span></div>
<div class="device-info-row"><span class="device-info-label">SRAM:</span><span class="device-info-value loading" id="di-sram">loading...</span></div>
```

In `dashboard/core/status-snapshot.js`, add to `DEVICE_INFO_MAP`:

### Task Group 3: Issue #138 — PSRAM Runtime Sensor

**Step 3.1 — Add PSRAM sensors for S3**

For the S3 YAML (if a separate S3 YAML exists), add:
```yaml
sensor:
  - platform: template
    name: "PSRAM Total"
    id: psram_total
    unit_of_measurement: "KB"
    lambda: |-
      return esp_psram_get_size() / 1024.0;
    update_interval: 60s

  - platform: template
    name: "PSRAM Free"
    id: psram_free
    unit_of_measurement: "KB"
    lambda: |-
      return heap_caps_get_free_size(MALLOC_CAP_SPIRAM) / 1024.0;
    update_interval: 60s
```
