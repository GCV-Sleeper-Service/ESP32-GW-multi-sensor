## §5 — Implementation Instructions

### Task Group 1: Issue #144 — Gateway Card Cleanup

**Step 1.1 — Update `DEVICE_INFO_MAP` in `dashboard/core/status-snapshot.js`**

Replace MAC address mapping with Device Name:
- Remove the MAC address entry from `DEVICE_INFO_MAP`
- Add `'di-device-name': {source: 'manifest', path: 'gateway.name'}` (or equivalent mapping pattern)
- Add `'di-firmware-version': {source: 'manifest', path: 'gateway.version'}`

**Step 1.2 — Update `dashboard/dashboard.tmpl.html`**

In the device info card template:
- Replace the MAC address row with a Device Name row using `id="di-device-name"`
- Add a Firmware Version row using `id="di-firmware-version"`
- Move Framework/ESPHome info to Documentation card (not device card)

**Step 1.3 — Populate from manifest in `dashboard/core/manifest.js`**

After manifest is loaded, populate the new fields:
```javascript
var nameEl = document.getElementById('di-device-name');
if (nameEl && manifest.gateway) nameEl.textContent = manifest.gateway.name || '—';
var verEl = document.getElementById('di-firmware-version');
if (verEl && manifest.gateway) verEl.textContent = manifest.gateway.version || '—';
```
