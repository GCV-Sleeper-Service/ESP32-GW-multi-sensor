### Task Group 4: V2-D — Status Field Strip + `/api/status/full`

**Step 4.1 — Replace public `/api/status` handler body**

Find the existing `handle_status_()` function. Replace the ENTIRE function body with a minimal response. The current handler uses `beginResponseStream` — replace with a simple `beginResponse` since the public response is now tiny.

The public response must contain ONLY these three fields:
```json
{"ok":true,"role":"satellite","id":"esp32-c3-multi"}
```

Derive `role` and `id` as follows:
- `role`: use `#if AGGREGATOR_ENABLED` → `"aggregator"`, `#else` → `"satellite"`
- `id`: use `App.get_name().c_str()` (ESPHome's global Application singleton — always available in component code)

```cpp
void handle_status_(AsyncWebServerRequest *request) const {
  // Auth: NOT REQUIRED — public health check; sensitive fields moved to /api/status/full
  const char *role = "satellite";
#if AGGREGATOR_ENABLED
  role = "aggregator";
#endif
  std::string body;
  body.reserve(128);
  body += "{\"ok\":true,\"role\":\"";
  body += role;
  body += "\",\"id\":\"";
  body += App.get_name().c_str();
  body += "\"}";
  auto *resp = request->beginResponse(200, "application/json", body.c_str());
  resp->addHeader("Cache-Control", "no-store");
  add_common_headers_(resp);
  request->send(resp);
}
```

**Step 4.2 — Add `/api/status/full` endpoint**

Add URL matching in `canHandle()`:

if (strcmp(p, "/api/status/full") == 0) return true;

**⚠️ Rule 8 — do NOT use `beginResponseStream`.** Use pre-reserved `std::string` + `beginResponse`:

```cpp
void handle_status_full_(AsyncWebServerRequest *request) const {
  // Auth: REQUIRED — full status with heap, version, uptime, telemetry (SEC-04)
  if (!authenticate_management_(request)) return;

  const char *role = "satellite";
#if AGGREGATOR_ENABLED
  role = "aggregator";
#endif

  uint32_t uptime_s = (uint32_t)(esp_timer_get_time() / 1000000LL);
  uint32_t free_heap_internal = esp_get_free_internal_heap_size();
  uint32_t free_heap_total = esp_get_free_heap_size();
  uint32_t min_free_heap = esp_get_minimum_free_heap_size();
  UBaseType_t httpd_wm = uxTaskGetStackHighWaterMark(nullptr);
  uint32_t httpd_wm_bytes = (uint32_t)(httpd_wm * sizeof(StackType_t));

  // Build complete JSON response using pre-reserved string (Rule 8).
  std::string json;
  json.reserve(1024);  // generous reserve for full response with sensors array
  char num[96];

  json += "{\"ok\":true,\"role\":\"";
  json += role;
  json += "\",\"id\":\"";
  json += App.get_name().c_str();
  json += "\",\"version\":\"";
  json += firmware_version_;
  json += "\",";

  snprintf(num, sizeof(num), "\"uptime_seconds\":%u,\"sensor_count\":%d,",
           (unsigned)uptime_s, NUM_DEVICES);
  json += num;

  // sensors array — same format as the old /api/status
  json += "\"sensors\":[";
  for (int i = 0; i < NUM_DEVICES; i++) {
    if (i > 0) json += ",";
    json += "{\"id\":\"";
    json += devices[i].id;
    json += "\",\"name\":\"";
    json += devices[i].name;
    const char *cat = "unknown";
    if (devices[i].category_id == 0) cat = "environmental";
    else if (devices[i].category_id == 1) cat = "system";
    else if (devices[i].category_id == 2) cat = "network";
    json += "\",\"category\":\"";
    json += cat;
    snprintf(num, sizeof(num), "\",\"last_seen\":%u",
             (unsigned)devices[i].last_seen_epoch);
    json += num;
    if (devices[i].category_id == 0) {
      snprintf(num, sizeof(num), ",\"temp_valid\":%s,\"hum_valid\":%s",
               devices[i].temp_valid ? "true" : "false",
               devices[i].hum_valid ? "true" : "false");
      json += num;
    }
    json += "}";
  }
  json += "],";

  snprintf(num, sizeof(num), "\"ram_history_points_per_series\":%d,", HISTORY_POINTS_PER_SERIES);
  json += num;
  snprintf(num, sizeof(num), "\"persist_days\":%d,", PERSIST_DAYS);
  json += num;
  snprintf(num, sizeof(num), "\"free_heap\":%u,", (unsigned)free_heap_internal);
  json += num;
  snprintf(num, sizeof(num), "\"free_heap_internal\":%u,", (unsigned)free_heap_internal);
  json += num;
  snprintf(num, sizeof(num), "\"free_heap_total\":%u,", (unsigned)free_heap_total);
  json += num;
  snprintf(num, sizeof(num), "\"min_free_heap\":%u,", (unsigned)min_free_heap);
  json += num;
  snprintf(num, sizeof(num), "\"httpd_stack_watermark_bytes\":%u,", (unsigned)httpd_wm_bytes);
  json += num;
  snprintf(num, sizeof(num), "\"ping_stack_watermark_bytes\":%u}",
           (unsigned)g_ping_stack_watermark_bytes);
  json += num;

  auto *resp = request->beginResponse(
      200, "application/json",
      reinterpret_cast<const uint8_t *>(json.data()), json.size());
  resp->addHeader("Cache-Control", "no-store");
  add_common_headers_(resp);
  request->send(resp);
}
```

**Step 4.3 — Update `fetch_to_buffer()` to support Basic Auth**

In `firmware/core/aggregator-runtime.h`, extend the `fetch_to_buffer()` signature. Current signature has 6 parameters; add a 7th:

```cpp
static bool fetch_to_buffer(const char* url, char* buf, uint16_t buf_size, uint16_t* out_len,
                            int timeout_s = 5, int* out_http_status = nullptr,
                            const char* basic_auth = nullptr)
```

Inside the function, when constructing the HTTP request headers, if `basic_auth` is non-null, add the Authorization header:
```
Authorization: Basic <basic_auth>\r\n
```

The `basic_auth` parameter should be a pre-encoded base64 string (e.g., `"YWRtaW46cGFzcw=="` for `admin:pass`). All existing callers that do not pass `basic_auth` are unaffected (default is `nullptr`).
