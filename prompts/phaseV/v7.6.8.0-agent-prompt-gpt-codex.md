### Task Group 4: V2-D — Status Field Strip + `/api/status/full`

**Step 4.1 — Modify public `/api/status` handler**

Find the existing `/api/status` handler. Modify response to return only:

```json
{"ok":true,"role":"satellite","id":"sat-c3-001"}
```

Remove from the public response: `version`, `free_heap`, `free_heap_internal`, `uptime_s`, `wifi_rssi`, `hardware`.

```cpp
// Auth: NOT REQUIRED — public health check; sensitive fields moved to /api/status/full
```

**Step 4.2 — Add `/api/status/full` endpoint**

Add to `canHandle()`:
```cpp
if (request->url() == "/api/status/full") return true;
```

Add handler:
```cpp
// Auth: REQUIRED — full status with heap, version, uptime (SEC-04)
if (!authenticate_management_(request)) return;
// Return complete status JSON (same fields as the old /api/status response)
```

Build the full response including: `ok`, `role`, `id`, `version`, `free_heap`, `free_heap_internal`, `uptime_s`, `wifi_rssi`.

**Step 4.3 — Update `fetch_to_buffer()` to support Basic Auth**

In `firmware/core/aggregator-runtime.h`, extend the `fetch_to_buffer()` signature. Current signature has 6 parameters (as of v7.6.7.0); add a 7th:

```cpp
static bool fetch_to_buffer(const char* url, char* buf, uint16_t buf_size, uint16_t* out_len,
                            int timeout_s = 5, int* out_http_status = nullptr,
                            const char* basic_auth = nullptr)
```

Inside the function, when constructing the HTTP request headers, if `basic_auth` is non-null, add:
```
Authorization: Basic <basic_auth>\r\n
```

All existing callers that do not pass `basic_auth` are unaffected (default is `nullptr`).

**Step 4.4 — Update aggregator polling**

Find the aggregator polling code that fetches `/api/status` from satellites. Change the URL to `/api/status/full` and pass the credentials via the new `basic_auth` parameter.

Check how the aggregator stores satellite credentials in `aggregator-runtime.h` and use that source. If credentials are not stored per-satellite, use the compile-time management credential.
