## Exact scope

Remove `SensorSlot`. Switch ALL runtime paths to `SensorEntity`. Add persistence shims.

**Step-by-step:**

1. **Remove SensorSlot generation** from `render_sensor_config.py` — only generate `SensorEntity devices[]`
2. **Remove `SensorSlot` struct** from `sensor_history_multi.h` (keep `SensorEntity` definitions)
3. **Rename `NUM_SENSORS` to `NUM_DEVICES`** (or alias: `static constexpr int NUM_SENSORS = NUM_DEVICES;` for backward compat)
4. **Remove dual-write** from YAML lambdas — keep only `devices[i].add_sample()` calls
5. **Update 15-minute timer** — remove `sensors[i].compute_and_format()`, keep `devices[i].compute_averages()`; generate avg strings from `devices[i]` metric_states
6. **Add persistence shims** — bridge `SensorEntity` ↔ `SegmentSnapshot` for NVS write and boot restore
7. **Update `handle_history_()`** — read from `devices[]` instead of `sensors[]`
8. **Update `handle_status_()`** — read from `devices[]` if needed
9. **Update `clear_all_sensors_()`** — clear `devices[]` state
10. **Update import handlers** — write to `devices[]` instead of `sensors[]`
11. **Keep `/sensors.json`** backward compat endpoint — generate from `devices[]`
12. **Keep `SegmentSnapshot` format** UNCHANGED

**CRITICAL CONSTRAINTS:**
- `SegmentSnapshot` format MUST NOT change (temp[NUM_SENSORS][POINTS], hum[NUM_SENSORS][POINTS])
- NVS key naming MUST NOT change
- Import/export paths MUST work (both multi-sensor and single-sensor merge)
- The `NUM_SENSORS` constant is used in `SegmentSnapshot` — it must stay or be aliased
