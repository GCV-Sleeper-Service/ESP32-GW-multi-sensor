**Check 3 — `no_generator_markers_in_fragments`:**
```bash
no_generator_markers_in_fragments() {
  # Fragment stubs contain the MARKER delimiter lines (BEGIN/END) but must NOT contain
  # generated content between them. Check for content lines between markers.
  local violations=0
  for f in firmware/core/*.h; do
    # Count lines between HEADER_BEGIN and HEADER_END (excluding the markers themselves)
    local header_content
    header_content=$(sed -n '/SENSOR_MANIFEST:HEADER_BEGIN/,/SENSOR_MANIFEST:HEADER_END/{ /SENSOR_MANIFEST:HEADER_BEGIN/d; /SENSOR_MANIFEST:HEADER_END/d; p; }' "$f" | wc -l)
    local entity_content
    entity_content=$(sed -n '/SENSOR_MANIFEST:ENTITY_BEGIN/,/SENSOR_MANIFEST:ENTITY_END/{ /SENSOR_MANIFEST:ENTITY_BEGIN/d; /SENSOR_MANIFEST:ENTITY_END/d; p; }' "$f" | wc -l)
    if [[ "$header_content" -gt 0 || "$entity_content" -gt 0 ]]; then
      echo "    Generated content found in $f (header=$header_content, entity=$entity_content lines)"
      violations=1
    fi
  done
  if [[ $violations -eq 0 ]]; then
    pass "no_generator_markers_in_fragments"
  else
    fail "no_generator_markers_in_fragments"
  fi
}
```

**Check 6 — `mutex_single_owner`:**
```bash
mutex_single_owner() {
  # s_cache_mutex must be defined in aggregator-runtime.h and nowhere else
  # Strip comment lines before counting — ping-adapter.h has boundary comments
  # referencing s_cache_mutex which are documentation, not definitions.
  local agg_count other_count
  agg_count=$(grep -v '^\s*//' firmware/core/aggregator-runtime.h | grep -c "s_cache_mutex" 2>/dev/null || echo 0)
  other_count=0
  for f in firmware/core/*.h; do
    [[ "$f" == "firmware/core/aggregator-runtime.h" ]] && continue
    local c
    c=$(grep -v '^\s*//' "$f" | grep -c "s_cache_mutex" 2>/dev/null || echo 0)
    other_count=$((other_count + c))
  done
  if [[ "$agg_count" -gt 0 && "$other_count" -eq 0 ]]; then
    pass "mutex_single_owner"
  else
    echo "    s_cache_mutex: aggregator-runtime.h=$agg_count, other fragments=$other_count"
    fail "mutex_single_owner"
  fi
}
```

**⚠️ IMPORTANT:** The `mutex_single_owner` check verifies that `s_cache_mutex` is not DEFINED in other fragments. `web-handler.h` may REFERENCE the mutex (via `AGG_LOCK`/`AGG_UNLOCK`) which is correct — it's the definition that must be unique. `ping-adapter.h` lines 160–168 contain a boundary documentation comment referencing `s_cache_mutex` — this is NOT a definition, just documentation. The updated check above strips comment lines (`grep -v '^\s*//'`) before counting to avoid these false positives.

Add all 6 function calls to the main check sequence in `preflight.sh`.
