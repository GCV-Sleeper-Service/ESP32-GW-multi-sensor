### 4. New lessons or Critical Rules?

Added in this cycle (via deliverable):
- **BUG-084**: Heap exhaustion under concurrent HTTP connections on non-PSRAM boards
- **LESSON-OPS-129**: Agent prompts must distinguish directly-modified files from pipeline-regenerated files
- **LESSON-OPS-130**: patch-esphome-httpd-stack.sh --check drift warning is expected
- **LESSON-OPS-131**: IRAM optimization is counterproductive when heap is the bottleneck

Candidate from PR #201 session log (not yet numbered):
- **LESSON-OPS-132 candidate**: Version-bump sessions must synchronize ALL canonical version sources (VERSION, render_sensor_config.py, generate-fixtures.js, app-shell.js, dashboard.html, firmware/core/*.h fragment headers) before running the pipeline. Running pipeline with partial version updates causes cascading preflight failures.
