### Critical invariants

- All new board profiles MUST include the `external_components` block (Critical Rule 42 / BUG-083)
- All new partition tables MUST have `ota_0` at 0x10000 (BUG-061)
- C5 profile MUST include `CONFIG_XTAL_FREQ_48: 'y'` (48 MHz crystal, not 26 MHz)
- C5 partition table: 8 MB layout (not 4 MB, not 16 MB)
- S3 SuperMini and C6 SuperMini: 4 MB partition layout (same as C3/WROOM)
- Existing board profiles and partition tables are UNCHANGED

### Regenerated files note

A version bump in `render_sensor_config.py` triggers pipeline regeneration of ~20+ generated
files (dashboard assets, manifests, fixtures, firmware YAML version strings, assembled headers).
This is expected behavior per Critical Rule 37, not scope creep. The agent prompt lists only
directly modified files under "Files created" and "Files modified". The regenerated files are
a known side effect of the pipeline. See LESSON-OPS-129.

  • `ota_0` at 0x10000 in all 3? (BUG-061)
