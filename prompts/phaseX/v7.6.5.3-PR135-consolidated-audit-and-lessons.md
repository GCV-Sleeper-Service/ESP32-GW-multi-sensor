### Issue classifications:

**Prompt omission (High severity):**
- The initial prompt did not mention adding `scripts/build-dashboard.sh` and `scripts/bundle-dashboard.sh` to the Browser Tests workflow path filters. Script-only changes could bypass CI, weakening the new `--check` gates.

**Prompt ambiguity (Medium/Low severity):**
- The prompt and session handoff contained conflicting pipeline orderings (`render → fixtures → bundle` vs `bundle → render → fixtures`). The agent followed the prompt text, which did not match the actual `bump-version.sh` behavior or the documented rationale.
- The header string wording (`dashboard/src/*.js + dashboard.tmpl.html`) was provided in the prompt but described indirect sources rather than direct build inputs. The fix (`dashboard.tmpl.html + dashboard.js (bundled from dashboard/src/*.js)`) better reflects the actual data flow.

**Autonomous decision (Medium severity):**
- The session log compliance table claimed the full 8-step pipeline was executed by `bump-version.sh`, but the script actually runs a 6-step subset (no fixture generation). This was an agent error in writing the compliance table, not a functional issue.
- The "Do NOT modify test files" row was marked compliant despite fixture version files changing. The prompt wording was ambiguous — it should have said "Do not modify test logic; fixture version files will be updated by `bump-version.sh`."

### 2. Pipeline ordering (Medium)
**Use a single normative pipeline block:**
```markdown
## Canonical Regeneration Pipeline

**Full manual regeneration (8 steps):**
1. bash scripts/bundle-dashboard.sh --write          # MUST run first to avoid wiping markers
2. python3 scripts/render_sensor_config.py --write
3. node tests/fixtures/generate-fixtures.js
4. python3 scripts/render_sensor_config.py --write
5. bash scripts/build-dashboard.sh --write
6. bash scripts/minify-dashboard.sh
7. bash scripts/generate-header.sh
8. python3 scripts/render_sensor_config.py --check

**Bump-version subset (6 steps, no fixture generation):**
1. bash scripts/bundle-dashboard.sh --write
2. python3 scripts/render_sensor_config.py --write
3. bash scripts/build-dashboard.sh --write
4. bash scripts/minify-dashboard.sh (conditional — only if .min.html exists)
5. bash scripts/generate-header.sh
6. bash scripts/preflight.sh

All documentation must use this exact ordering. Bundle MUST run first.
```
