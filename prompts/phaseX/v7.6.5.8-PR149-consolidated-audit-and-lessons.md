## Lessons for Future Closure Steps

1. **Prompt should explicitly state version-bump scope** for closure/docs-only steps — "run bump-version.sh" or "do NOT run bump-version.sh"
2. **All pre-merge documents must use branch-aware language** — add to Critical Rules: "Status statements in docs added by a PR must be true pre-merge; use 'on this branch / pending merge' wording"
3. **File count arithmetic should be machine-verified** — preflight checks N files, docs should derive from that count, not be hand-calculated
4. **Multi-reviewer cycles inflate commit count** — consider batching reviewer invocations after fix commits land, not before
