## 5. Exact Scope

### 5a. Identify HTML sections for each component

Read `dashboard/dashboard.tmpl.html` and identify the HTML blocks for each component by their DOM identifiers:

| Component | DOM identifiers to locate |
|-----------|--------------------------|
| `device-info` | `#c3DescriptionBlock`, `.top-grid` |
| `sensor-cards` | `#sensorGrid` |
| `charts` | `.charts-row`, `#chartSection` |
| `settings-panel` | `#storageCard`, `#exportSection` |
| `custom-range` | `#customRangeModal` |
| `auth-modal` | `#authModal` |
| `live-view` | `#telemetrySection` |
| `gateway-panel` | `#hdr-gateways`, `#gwSelector` |

### 5b. Create `template.html` for each component

Extract each HTML section into its component directory. The extracted content is the complete HTML block — from the outermost container `<div>` through its closing tag — exactly as it appears in the template. **No whitespace changes. No prettification.**

```
dashboard/components/device-info/template.html
dashboard/components/sensor-cards/template.html
dashboard/components/charts/template.html
dashboard/components/settings-panel/template.html
dashboard/components/custom-range/template.html
dashboard/components/auth-modal/template.html
dashboard/components/live-view/template.html
dashboard/components/gateway-panel/template.html
```

**Note:** The existing C3 board SVG inside the device-info section is extracted as part of `components/device-info/template.html` — no new SVG creation required.

### 5c. Replace extracted sections in `dashboard.tmpl.html`

Replace each extracted HTML section with a `{{COMPONENT:name}}` marker:

```html
{{COMPONENT:device-info}}
{{COMPONENT:sensor-cards}}
{{COMPONENT:charts}}
...
```

The marker sits on its own line at the exact position where the HTML block was.

### 5d. Update `scripts/build-dashboard.sh` for two-pass assembly

```
Pass 1: For each {{COMPONENT:name}} in dashboard.tmpl.html,
        substitute contents of dashboard/components/<name>/template.html.
        → Produces fully-assembled HTML shell (all panels inlined).

Pass 2: Inject dashboard.js at {{JS_PLACEHOLDER}}.
        → Produces final dashboard/dashboard.html.
```

The `<!-- GENERATED -->` header added at v7.6.5.3 is preserved.

### 5e. Verify two-pass output matches v7.6.5.4 output
